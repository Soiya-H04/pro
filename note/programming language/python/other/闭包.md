# 闭包

## 一、什么是闭包

闭包（Closure）是指**内部函数**引用**外部函数**的变量（**非全局变量**），并且**外部函数**返回**内部函数**的一种结构。

闭包 = 函数 + 环境变量（函数定义时的上下文）。

-   **函数里面套函数，里面函数能用外面函数的变量**

```python
# 设计闭包
def outer(out_var):
    # 外部函数逻辑
    def inner(in_var):
        # 使用外部变量
        nonlocal out_var
        # 内部函数逻辑
    return inner
```

## 二、修饰器

修饰器在函数原有基础上**添加功能**而**不改变原**函数内容。

修饰器本质还是一个**闭包**。

```python
# 创建修饰器
# 传入要修饰的函数 function
def outer(function):
    def inner():
        # 添加功能
        function
        # 添加功能
	return inner
```

```python
# 使用修饰器 outer 修饰 function 函数
@outer
function
```
