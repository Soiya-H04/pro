# 随机数

## 一、随机概念

Python 里生成随机数是生成的伪随机数，即根据一定条件生成一个特定的数。

## 二、生成随机数

Python 里生成随机数使用 `random `库

``` python
import random
```

### 2.1 随机种子

随机种子 为 `int/float/str` ，Python 通过对一个随机种子进行特定运算得到一个伪随机数。对于同一个随机种子，生成的伪随机数**不变**

```python
# 设置随机种子
random.seed(12.2121)
random.seed("stee")
random.seed(10)
```

### 2.2 random()

```python
# 生成[0.0, 1.0)范围内的随机浮点数
random.random()
```

### 2.3  uniform(a, b)

```python
# 生成[a, b]范围内的随机浮点数
random.uniform(a, b)
```

### 2.4 randint(a, b)

```python
# 生成[a, b]范围内的随机整数
randint(a, b)
```

### 2.5 randrange(start, stop[, step])

```python
# 生成 range(start, stop[, step]) 之间的随机数
randrange(start, stop[, step])
```

## 三、随机序列生成

### 3.1 choice(seq)

```python
# 从序列中随机选择一个元素
random.choice(seq)
```

### 3.2 choices(seq, k = n)

```python
# 从序列中随机选择 n 个元素（可重复）
random.choices(seq, k=n)
```

### 3.3 sample(seq, k = n)

```python
# 从序列中随机选择 n 个不重复的元素
random.sample(my_list, k=n)
```

### 3.4 shuffle(seq)

```python
# 将序列随机打乱（原地修改）
random.shuffle(seq)
```
