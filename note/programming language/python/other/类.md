# 类

## 一、类

### 1.1 面向对象编程

面向对象编程（Object-Oriented Programming，OOP）是一种**编程范式**，它将**数据**和**操作数据**的方法组织成**对象**，而不是**一系列步骤**。

在 Python 中，**一切皆对象**，OOP 是 Python 的核心特性。

### 1.2 类

**类（Class）** 是面向对象编程（OOP）的核心概念，它是一种**自定义**的数据类型，用于封装**数据（attribute）**和**操作数据的方法（method）**。

### 1.3 属性

**属性（attribute）**是定义在类中的**变量**，定义对象的状态。

### 1.4 方法

**方法（Method）**是定义在类中的**函数**，用于定义对象的行为

### 1.5 创建基本类

```python
# 创建基本类 class_name
class class_name:
    # 属性
    # 方法
```

### 1.6 实例化

**实例化（Instantiation）** 是创建对象（类的一个实例）的过程。

```python
# 将类 class_name 实例化
instance = class_name()
```

## 二、属性

### 2.1 类属性

类属性属于**类本身**，所有实例**共享**同一个类属性。

```python
# 创建类属性(通常大写)
class class_name:
    CLASS_ATTR = default_value
```

```python
# 访问类属性
# 用类实例 inst 进行访问 
inst.CLASS_ATTR
# 用类本身 class_name 进行访问
class_name.CLASS_ATTR
```

### 2.2 实例属性

实例属性属于具体的**对象实例**，每个实例都有自己的副本。

```python
# 创建实例属性
# 在 __init__() 方法里进行创建
# 可以设置 default_value
class class_name:
    def __init__(self,value)
	    self.inst_attr1 = value
        self.inst_attr2 = default_value
```

```python
# 访问实例属性
# 创建实例时需要传进属性值
# 可以位置传值与关键字传参
inst = class_name(value1, inst_attr2 = value2)

# 访问实例属性
inst.inst_attr1
inst.inst_attr2
```

### 2.3 私有属性

私有属性只能**内部访问**。

```python
# 使用双下划线加属性名创建私有属性 __attr
# 创建私有类属性
class class_name:
    __CLASS_ATTR = default_value
    
# 创建私有实例属性
class class_name:
    def __init__(self,value)
	    self.__inst_attr1 = value
        self.__inst_attr2 = default_value
```

### 2.4 属性赋值

创建的类可以对类属性进行赋值。

```python
# 赋值没有的类属性,会创建新的类属性
class_name.new_class_attr = value

# 赋值已有非私有类属性,会修改类属性值
class_name.class_attr = value
```

创建的实例可以对实例属性进行赋值。

```python
# 赋值没有的实例属性,会创建新的实例属性
class_name.new_inst_attr = value

# 赋值已有非私有实例属性,会修改实例属性值
class_name.inst_attr = value
```

### 2.5 删除属性

```python
# 删除已存在的属性
del class_name.attr
```

## 三、方法

### 3.1 实例方法

对**实例**进行操作的方法。

```py
# 创建实例方法
# 第一个参数传 self, 表示是属于这个实例的方法
# 可以根据 self 调用实例属性
class class_name:
    def inst_method(self, param):
        # 方法逻辑
```

```python
# 调用实例方法
inst = class_name()	
inst.inst_method(param)
```

### 3.2 类方法

对**类**进行操作的方法。

```python
# 创建类方法
# 在类方法上要加上修饰器 @classmethod, 第一个参数传 cls，表示是属于类的方法
# 可以根据 cls 调用属性
class class_name:
    @classmethod
    def class_method(cls, param):
        # 方法逻辑
```

```python
# 调用类方法
# 通过类直接调用
class_name.class_method(param)

# 通过实例调用
inst = class_name()
inst.class_method(param)
```

### 3.3 静态方法

逻辑上属于类的方法，只是定义在类里的函数。

```python
# 创建静态方法
# 在静态方法上要加上修饰器 @staticmethod
class class_name:
    @static
    def static_method(param):
        # 方法逻辑
```

```python
# 调用类方法
# 通过类直接调用
class_name.static_method(param)

# 通过实例调用
inst = class_name()
inst.static_method(param)
```

### 3.4 特殊方法（魔法方法）

以 `__` 开头与结尾的方法，控制一系列类的特定行为。

类里自带，可根据需要重写

#### A. `__init__()`

实例化时进行的初始化方法。

```python
# 修改 __init__() 方法, 传进 self(实例)
# 在 __init__() 传进的参数要在实例化类是传进类里
class class_name:
    def __init__(self, param1, param2...):
        # 初始化逻辑
```

```python
# 根据 __init__() 进行实例初始化
inst = class_name(param1, param2 ...)
```

#### B. `__new__()`

实例化前执行的方法。

```python
# 修改 __new__() 方法, 传进 cls(类)
# 但必须要传回实例，不然实例无法创建
class class_name:
    def __new__(cls):
        # 初始化前逻辑
        # 调用父类 super().__new__()进行传回
        instance = super().__new__(cls)
        return instance
```

#### C. `__str__()`

实例序列化（变为字符串）时要显示的内容。

```python
# 修改 __str__() 方法
class class_name:
    def __str__(self):
        # print(inst) 或 str(inst)时的显示逻辑
```

#### D. `__del__()`

删除实例之前执行的操作。

```python
# 修改 __del__() 方法
class class_name:
    def __del__(self):
        # 删除前执行逻辑
```

#### E. 容器类型

| 方法名                          | 用途                  | 对应操作/函数               |
| ------------------------------- | --------------------- | --------------------------- |
| `__len__(self)`                 | 返回容器长度          | `len(obj)`                  |
| `__getitem__(self, key)`        | 获取指定键/索引的元素 | `obj[key]`, `obj[i:j]`      |
| `__setitem__(self, key, value)` | 设置指定键/索引的元素 | `obj[key] = value`          |
| `__delitem__(self, key)`        | 删除指定键/索引的元素 | `del obj[key]`              |
| `__contains__(self, item)`      | 检查是否包含元素      | `item in obj`               |
| `__iter__(self)`                | 返回迭代器            | `for x in obj`, `iter(obj)` |

#### F. 比较运算

| 方法名                | 用途         | 对应操作/函数                 |
| --------------------- | ------------ | ----------------------------- |
| `__eq__(self, other)` | 等于比较     | `obj == other`                |
| `__ne__(self, other)` | 不等于比较   | `obj != other`                |
| `__lt__(self, other)` | 小于比较     | `obj < other`                 |
| `__le__(self, other)` | 小于等于比较 | `obj <= other`                |
| `__gt__(self, other)` | 大于比较     | `obj > other`                 |
| `__ge__(self, other)` | 大于等于比较 | `obj >= other`                |
| `__hash__(self)`      | 返回哈希值   | `hash(obj)`, 用于字典键和集合 |
| `__bool__(self)`      | 布尔值转换   | `bool(obj)`, `if obj:`        |

#### G. 属性访问

| 方法名                           | 用途               | 对应操作/函数                |
| -------------------------------- | ------------------ | ---------------------------- |
| `__getattr__(self, name)`        | 当属性不存在时调用 | `obj.attribute` (属性不存在) |
| `__getattribute__(self, name)`   | 访问任何属性时调用 | `obj.attribute`              |
| `__setattr__(self, name, value)` | 设置属性时调用     | `obj.attribute = value`      |
| `__delattr__(self, name)`        | 删除属性时调用     | `del obj.attribute`          |
| `__dir__(self)`                  | 返回属性列表       | `dir(obj)`                   |
| `__delete__(self, instance)`     | 描述符删除         | `del obj.attribute` (描述符) |
| `__slots__`                      | 限制实例属性       | 类变量（不是方法）           |

## 四、继承

**继承**允许一个类（子类）继承另一个类（父类）的**属性（类属性，实例属性）**和**方法**。

### 4.1 继承格式

#### A. 单继承

```python
# 创建父类 parent
class parent:
    # 父类逻辑

# 创建子类 child 并继承父类 parent
class child(parent):
    # 子类逻辑
```

#### B. 多继承(简单)

```python
# 创建父类 parentA 与 parentB
class parentA:
    # 父类逻辑
class parentB:
    # 父类逻辑

# 创建子类 child 并继承父类 parent
class child(parentA, parentB):
    # 子类逻辑
```

#### C.多继承（一般）

```python
# 创建父类 parentA、 parentB、 parentC
class parentA:
    # 父类逻辑
class parentB(A):
    # 父类逻辑
class parentC(A):
    # 父类逻辑

# 创建子类 child 并继承父类 parent
class parent(parentB, parentC):
    # 子类逻辑
```

### 4.2 MRO

使用多继承时，如果多个父类有同名方法或属性（如`__init__`），使用**MRO（Method Resolution Order，方法解析顺序）** 来确定调用哪个父类的方法。

MRO 主要遵循**C3线性化算法**，确保：

1.  **子类优先于父类**
2.  **继承列表中靠前的父类优先**
3.  **保持单调性**（monotonicity）

#### A. 方法继承

-   父类未重名方法**全部**被子类继承
-   父类重名方法按照 MRO 被子类继承

#### B. 属性继承

-   子类继承父类未重名**全部类属性**
-   子类按照 MRO 继承父类重名**类属性**
-   子类按照 MRO 继承最近父类的 `__init__()` 定义的**实例属性**

### 4.3 重写方法

子类对于父类存在的方法进行重新编写

```python
# 对于父类 parent 的 method 方法进行重写
class parent:
    def method(self):
        # 父类方法逻辑

# 子类重写 method        
class child(parent):
    def method(self):
        # 子类方法逻辑
```

### 4.4 执行父类方法

在子类内能执行父类方法。

#### A. `super().method()`

根据 MRO 来选择最近的父类方法。

```python
# 执行父类方法
class parent:
    def parent_method(self):
        # 父类方法逻辑
    
class child(parent):
    super().parent_method()
```

#### B. `parent.method()`

```python
# 执行父类方法
# 需要加 self 或 cls
class parent:
    def parent_method(self):
        # 父类方法逻辑
    
class child(parent):
    def method(self):
 	   parent.parent_method(self)
	    # 子类方法逻辑
```

## 五、多态

完成**同一个**行为，**传入对象**不同，**实现逻辑**不同。

### 5.1 抽象类

只定义方法，不具体实现的类，充当模版。

#### A. 模版创建

使用 `abc` 库中的 `ABC` 与 `abstractmethod`

-   子类必须实现抽象方法

```python
# 创建抽象类
from abc import ABC, abstractmethod

class AbstractClass(ABC):
    @abstractmethod
    def method(self):
		pass
```

#### B. 简单创建

-   子类可以不实现抽象方法

```python
class AbstractClass:
    @abstractmethod
    def method(self):
		pass
```

### 5.2 多态原理

多个继承同父类的类传进一个调用子类都重写过的方法，使用模板创建**抽象类**可以实现。

```python
# 实现多态
def function(parent):
    parent.method()

function(child)
```
