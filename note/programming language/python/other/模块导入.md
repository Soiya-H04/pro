# 模块导入

## 一、模块

模块就是 Python 文件，以 .py 结尾。可以包含类、变量、模块、函数已经可执行的代码等。

模块的作用就是能够快速实现一些功能，不需要在当前文件中再进行**代码细节的实现**。

## 二、模块导入

### 2.1 Python 模块

```python
# 导入整个 module.py 模块,不需要加 .py
import module
```

```python
# 导入整个 module.py 模块并起别名 alias
import module as module_alias
```

### 2.2 Python 模块内的特定对象

```python
# 导入 module.py 模块内的对象(类、函数、变量、模块),用 , 隔开,用 * 导入所有对象
from module import [module | class | function | varible| *]
```

```python
# 导入 module.py 模块内的对象(类、函数、变量、模块)并起别名 alias
from module import [module as module_alias |class as class_alias|function as function_alias|varible as varible_alias]
```

## 三、 模块使用

### 3.1 导入 Python 模块的使用

```python
# 使用 module.py 中的 function,要用 . 进行调用
import module
module.funnction
```

### 3.2 导入 Python 模块内的特定对象的使用

```python
# 直接 module.py 中的 function
function
```

-   导入模块的对象名尽量与本文件的对象名**不要一致**，如果重名进行**别名改写**。
-   若对象名冲突，会优先使用本文件对象

### 3.3 导入自定义模块的使用

对于自己编写的 Python 文件也是可以导入的，而且导入优先级**高于**内置模块，即如果同目录下有与内置 Python **重名**的自定义模块，会优先导入自定义模块

#### A. 模块内可运行代码

如果自定义模块有可运行代码，在导入时会运行

>   解决方法：
>
>   ```python
>   # 将可运行代码放进 main 块中
>   if __name__ == '__main__':
>       # 可运行代码
>   ```

#### B. 模块允许导入对象

使用 `*` 可以导入模块中所有允许被导入对象

```python
# 在 module.py 文件中,允许被导入的对象放在 __all__ 块中,为一个列表
# 将允许被导入的对象名的字符串放进 __all__ 中代表运行被导入(不写默认为所有都允许)
__all__ = ['function','class']
```
