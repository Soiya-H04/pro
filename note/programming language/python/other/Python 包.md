# Python 包

## 一、包

**包（Package）** 是包含多个模块（module）的文件夹，用于组织相关的模块。一个包**必须包含**一个特殊的文件 **\__init\__.py**

### 1.1 包的结构

```text
# 一个 Python 包内可以有子包
mypackage/
├── __init__.py
├── module1.py
└── subpackage/
    ├── __init__.py
    └── module2.py
```

### 1.2 包的作用

| 特性         | 普通文件夹     | Python 包            |
| ------------ | -------------- | -------------------- |
| **身份标识** | 只是文件夹     | 必须有 `__init__.py` |
| **导入方式** | 直接导入模块   | 通过包名.模块名导入  |
| **命名空间** | 全局，易冲突   | 独立命名空间         |
| **可分发性** | ❌ 不能打包发布 | ✅ 可发布到 PyPI      |
| **依赖管理** | ❌ 没有         | ✅ 可定义依赖         |

-    **命名空间隔离**
-   **结构化组织**
-    **可分发性**

### 1.3 包的创建

-   使用 Pychram 内置创建
-   创建带有 **\__init\__.py **文件的文件夹

### 1.4 包的使用

在项目内创建的 Python 文件通过导入使用包内的模块

```python
# 使用 pakeage 中的 module
from pakeage import module
```

-   可以在 **\_\_init\_\_.py** 文件中些 **\_\_all\_\_** 进行对于包导入模块时的 `*` 的允许范围
