## 二、 异常捕获

对于可能出现的异常进行捕获与处理

### 2.1 基本结构

```python
# 捕获异常的基本结构,可以捕获所有异常
try:
	# 可能出现异常的代码    
except:
    # 进行异常处理
```

```python
# 捕获异常的顶级结构,可以捕获所有异常
try:
	# 可能出现异常的代码    
except Exception as e:
    # 进行异常处理
```

### 2.2 捕获特定异常

```python
# 捕获特定异常 SpecialError
try:
	# 可能出现异常的代码    
except SpecialError as e:
    # 进行异常处理
```

```python
# 捕获多个特定异常 SpecialError1, SpecialError2 采用元组结构进行捕获
try:
	# 可能出现异常的代码    
except (SpecialError1, SpecialError2) as e:
    # 进行异常处理
```

```python
# 捕获多个特定异常 SpecialError1, SpecialError2 并进行特定处理
# 对于其他异常进行宽泛处理
try:
	# 可能出现异常的代码    
except SpecialError1 as e1:
    # 进行特定异常处理
except SpecialError2 as e2:
    # 进行特定异常处理
except Exception as e3:
    # 进行宽泛异常处理
```

### 2.3 无异常处理

```python
# 无异常是进行操作放在 else 块中
try:
	# 可能出现异常的代码    
except SpecialError1 as e1:
    # 进行特定异常处理
except SpecialError2 as e2:
    # 进行特定异常处理
except Exception as e3:
    # 进行宽泛异常处理
else:
    # 无异常时处理
```

### 2.4 绝对处理

```python
# 无论有无异常都要进行的处理放在 finally 块中
# 无异常是进行操作放在 else 块中
try:
	# 可能出现异常的代码    
except SpecialError1 as e1:
    # 进行特定异常处理
except SpecialError2 as e2:
    # 进行特定异常处理
except Exception as e3:
    # 进行宽泛异常处理
else:
    # 无异常时处理
finally:
    # 有无异常都要进行的处理
```

### 2.5 异常传递

基于函数的调用，如果嵌套内的函数没有捕获异常，会将异常返回给调用的函数，如果调用的函数也没有捕获，会将异常返回给调用它的函数，直至对开始调用的函数。

==即只需要对最开始调用的函数进行异常捕获就可以了，不需要每一个函数都进行异常捕获==
