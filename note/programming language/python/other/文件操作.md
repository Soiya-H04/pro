# 文件操作

## 一、文件操作

Python 对文件有打开、关闭、读写的操作。

## 二、 文件开关

### 2.1 打开文件

Python 使用 `open()` 函数打开文件

```python
# 使用 mode 模式, encoding 编码方式打开 filename 为 file
file = open(filename, mode, encoding="encoding")
```

>   相关参数：
>   `filename`:打开文件路径
>
>   `mode`:打开模式
>
>   | 模式 | 描述                           |
>   | ---- | ------------------------------ |
>   | 'r'  | 只读模式（默认）               |
>   | 'w'  | 写入模式，会覆盖文件           |
>   | 'a'  | 追加模式，在文件末尾添加       |
>   | 'x'  | 独占创建模式，文件不存在则创建 |
>   | 'b'  | 二进制模式                     |
>   | 't'  | 文本模式（默认）               |
>   | '+'  | 读写模式                       |
>
>   `encoding`:编码方式
>
>   | 编码名称   | 字符集范围                        | 字节长度             |
>   | ---------- | --------------------------------- | -------------------- |
>   | **UTF-8**  | 所有Unicode字符（1,112,064个）    | 可变长度（1-4字节）  |
>   | **UTF-16** | 所有Unicode字符                   | 可变长度（2或4字节） |
>   | **UTF-32** | 所有Unicode字符                   | 固定4字节            |
>   | **GB2312** | 7445个字符（6763汉字）            | 可变长度（1-2字节）  |
>   | **GBK**    | 21886个字符                       | 可变长度（1-2字节）  |
>   | **ASCII**  | 128个字符（英文、数字、基本符号） | 固定1字节            |

-   对于一般的文件路径需要在文件前加 `r` 或者使用 `\\`才能正常读取

```python
# 文件路径处理
r"filename"

"file\\name"
```

### 2.2 关闭文件

Python 使用 `close()` 函数打开文件

```python
# 关闭 file
file.close()
```

### 2.3 with 语句

`with` 语句会自动处理文件的关闭，即使在发生异常时也能确保文件被正确关闭。

```python
# 打开文件
with open(filename, mode, encoding) as file:
    # 文件操作
```

## 三、文件读写

文件的读写根据指针来决定

### 3.1 文件指针

文件开始读写的位置一开始默认在文件开头位置

#### tell()

0 代表文件开头位置

```python
# 查询 file 指针位置
file.tell()
```

#### seek()

```python
# 移动 file 指针位置(绝对)
file.seek(n)
# 移动 file 指针位置（相对）
file.seek(move,n)
```

>   相关参数：
>   `file.seek(n)`:
>
>   `n`:要移动到的字符位置
>
>   `file.seek(move,n)`:
>
>   `move`:相对移动的字符数(`+` 为向后移动；`-` 为向前移动)
>
>   `n`:
>
>   | 数值 |     位置     |
>   | :--: | :----------: |
>   |  0   |   文件开头   |
>   |  1   | 当前指针位置 |
>   |  2   |   文件结尾   |

### 3.2 文件读取

#### A. read(n)

```python
# 读取文件指针后 n 个字符
file.read(n)
# 读取文件指针后所有支付
flle.read()
```

#### B. readline()

```python
# 读取文件指针后一行字符
file.readline()
```

#### C. readlines()

```python
# 读取文件指针后所有行的字符组成列表
file.readlines()
```

### 3.3 文件写入

#### A. write("text")

```python
# 将字符 text 写入 file 内
file.write("text")
```

#### B. writelines(seq)

```python
# 将列表里的元素依次写入 file 内
file.writelines(seq)
```

-    文件写入会先放进内存中并不会直接写入硬盘，即文件里不会立即被写入
-   `close()` 自带 `flush()` 的功能

#### C.  flush()

```python
# 在未关闭文件时，将内容写进 file 中
file.flush()
```
