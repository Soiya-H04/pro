# 关于编码风格
一个好的**编码风格**，不仅可以让代码看起来更轻松，也会让coder写的更加轻松有条理
借鉴[PE8](https://peps.python.org/pep-0008/)，规定统一的编码风格

---

# 编码风格
## 缩进
缩进严格使用四个空格，不使用制表符

## 最大行长度
一行最多编写79个字符，包含空格

## 空白行
使用不同空白行分隔不同代码块：
- 用两个空白行分割类与函数
- 用一个空白行类的方法

## 注释
注释单独放一行，并放在注释对象上方

## 文档字符串
使用文档字符串给函数与类进行简单介绍

## 空格
使用空格增加代码的可读性：
- 运算符前后看情况使用空格，代码过长考虑换行
- 逗号后看情况使用空格，代码过长考虑换行

## 命名
一般命名使用对命名对象的描述，不同类型对象命名标准不同：
- 类名使用驼峰，如MyClass
- 函数名、方法名全小写，如myfunction
- 变量名全小写，如myvariable
- 常量全大写，如MYCONST
- 模块名全小写，如mymodule
- 过长适当缩写或添加下划线_，如my_too_long_name_for_code

## 编码
不使用生僻的编码

## 导入
导入顺序：
- 系统库
- 第三方库
- 自定义库（本地库）
导入规则：
- 不同模块使用不同行导入，不在一行导入多个模块
- 导入模块使用确定的导入对象名，过长则使用`*`

# 总结
编码风格并不是一成不变，只是制定基本的编码准则，实际情况还是要看代码编写情况
