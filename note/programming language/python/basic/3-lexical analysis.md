# 行结构
行结构是很多coder编写很久代码以后都不会重视的事情，只是理所当然的就这么用了

想象以下，为什么Python知道一段代码在哪里结束，在C语言中是使用`;`来表示一行代码的结束，但Python不需要显式的结束一行代码

## 物理行
物理行是由一串字符与行尾字符（回车键对应的`\n`，`\n`为转义字符，后面会介绍）组成
敲下回车键实际就是输入了一个`\n`，表示该行结束，会切换到下一行，实现换行
如
```text
第一行物理行
第二行物理行
```

在多数时候`\n`不可见，有时可能会在文本里发现了`\n`，这就代表换行

## 逻辑行
一个程序可以被拆分为多个逻辑行，Python通过逐行（逻辑行）执行，进而实现相关逻辑
代码块实际就是多个属于同一层的逻辑行组成

逻辑行具有边界，限定编写的字符数，不能编写超出边界的逻辑行
[[2-code style#最大行长度|编码风格]] 中规定一个逻辑行最多不超过79个字符，可以很好限制逻辑行的字符数

一行物理行通常情况等价于一行逻辑行，即每一行算作一行逻辑行
通过显示拼接或隐式拼接可以使多行物理行表示为一行逻辑行
- 显示拼接
`\`是续行符，在末尾使用`\`来表示逻辑行未结束，会将下一行的内容接在上一行之后
如
```text
这是一行 \
逻辑 \
行
```

Python会将其解释为
```text
这是一行逻辑行
```

- 隐式拼接
隐式拼接是在使用括号（圆括号`()`、方括号`[]`、花括号`{}`）时，可以将其分成多个物理行
Python会自动将其转换为一行逻辑行
如
```python
(1, 
2, 
3, 
4, 
)
```

Python会将其解释为
```python
(1, 2, 3, 4)
```

## 注释
注释以`#`开头，占用一个物理行
注释用于描述代码作用，Python会在执行程序时，自动忽略该行，不执行该行的内容
如
```python
# 这是一行注释
```

之后的介绍会经常使用注释来进行解释，这会显示出注释对于代码而言的重要性

## 编码声明
用于指定代码的编码方式，必须独占一行物理行（且在Windows中必须在py文件的第一行）
很多py文件没有使用编码声明是因为Python会使用默认的"UTF-8"编码，规范而言，在编写代码时还是要规定编方式

假设编码方式为`<encoding-name>`，则声明方式为
```python
# -*- coding:<encoding-name> -*-
```

## 空白行
空白行是只包含空格符、制表符、换页符的逻辑行，会被Python忽略，一般用于不同代码块的间隔

## 缩进
缩进是逻辑行开头的空白符（空格符与制表符，最好使用 [[2-code style#最大行长度|编码风格]] 推荐的缩进方式），用来计算代码行的缩进层级进而决定代码块
缩进不能用显示拼接
如
```text
这是第一层
    这是第二层
    这是第二层
这是第一层
```

缩进最好不要混合使用空格符与制表符，否则将导致不能正常识别缩进的层级，进而出现报错（TabError）

由于Python使用这种缩进方式表示代码的层级，所以不能输入错误的缩进，否则Python将无法理解
如
```text
 空一格
  空两格
未空格
```

# 标识符与关键字
## 标识符
参与程序执行的对象会使用标识符表示，相当于给对象打上标签
一个对象可能拥有**多个**标识符
Python通过操作对象的标识符来操作对象

Python一般使用`=`（赋值符）为对象添加标识符
假设对象为`<object>`，要添加标识符`<identifier>`，语法为
```python
<identifier>=<object>
```

标识符具有传递性，即如果给一个有标识符的对象添加标识符，可以通过原标识符进行添加
假设对象为`<object>`，原标识符`<identifier-1>`，新添加标识符`<identifier-2>`，则使用方式为
```python
<identifier-2> = <identifier-1>
```

实际`<identifier-1>`是`<object>`的标识符，即`<identifier-1>`将`<object>`传递给了`<identifier-2>`

误区：使用`=`进行赋值时，经常说标识符被赋值
如
```python
a = 1
```

通常被说为a被赋值为1，即a的值为1，这并不是准确的说法
实际上是创建数学对象1并为其添加标识符a，数字对象1的值才是1

后面如果为对象添加标识符，会解释成为标识符赋值对象

某些时候，标识符又被叫做**变量名**，因为标识对象**可以改变**
根据标识对象类型不同又可以称为类名、函数名、模块名、列表名等

为对象添加标识符的要求：
- 可以使用大小写字母`A-Z`，`a-z`
- 可以使用`_`，但不能放在开头
- 可以使用数字，但不能放在开头
如
```text
abc11
s_21
SD_sa21102
```

## 关键字
有些标识符被Python使用，称为**关键字**，表示一些特殊的对象，执行相应操作
创建标识符时应该**避免使用**，不然会报错

Python使用的关键字如下
```text
False      await      else       import     pass
None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield
```

有些关键字需要在特定的情况才能被视为关键字，这样的关键字叫做**软关键字**，如`match`、`case`等

# 字面值
字面值是Python的常量（不可变的值）的表示方式，常量通常指的是**数字**与**字符串**
## 数字
Python中没有复数与负数，复数使用实数与虚数结合表示，而负数使用`-`来表示
### 整数
Python支持的整数格式有十进制、十六进制、八进制以及二进制
- 十进制
十进制是生活中常见的数字
十进制数可以使用`_`进行隔开，以便看的更清楚
如
```python
# 十进制
12
2111

# 使用_隔开，表示1000000000
1_000_000_000
```

- 十六进制
十六进制使用`0x`开头，后面接十六进制的表示
同样可以使用`_`隔开，一般是每两个十六进制
如
```python
# 十六进制
0x1F21

# 使用_隔开，表示3D4E3C
0x3D_4E_3C
```

- 八进制
八进制使用`0o`开头，后面接八进制的表示
同样可以使用`_`隔开，一般是每三个八进制
如
```python
# 八进制
0o137

# 使用_隔开，表示127634
0o127_634
```

- 二进制
二进制使用`0b`开头，后面接二进制的表示
同样可以使用`_`隔开，一般是每四个二进制
如
```python
# 二进制
0b10011010

# 使用_隔开，表示11110011
0b1111_0011
```

### 浮点数
Python支持的浮点型可以使用自然表示与科学计数表示
自然表示即为常见的小数形式，若整数部分为0或小数部分为0可省略
如
```python
# 自然表示1.2131，10.0，0.001
1.2131
10.
.001
```

科学计数使用`e`或`E`来表示乘以10的几次方
`e`或`E`的左边是乘以的小数部分，右边是乘以10的次方数，同样可以省略为0的整数或小数部分
如
```python
# 科学计数表示123000.0，-0.02211，0.005，2000.0
1.23e5
-2.211e-2
.5e-2
2.e3
```

### 虚数
Python使用`j`代表虚数部分
```python
# 表示虚数
10j

# 表示复数
12 + 1j
```

## 字符串
Python中，字符串就是一个多个字符的**组合**，并用**引号**包裹
字符串可以是英文单词或是中文（默认的编码支持中文）
字符串最常使用`""`包裹
如
```python
# 表示中文字符串
"这是一个字符串"

# 表示英文字符串
"this is a string"
```

还可以使用`''`或`""""""`（支持换行）包裹
如
```python
# 单引号
'this is a string.'

# 多引号
"""
this
is
a
string.
"""
```

如果字符串自带引号，字符串使用双引号包裹，里面的引号使用单引号（反过来也可以）
如
```python
# 双引号包裹单引号
"I'm Tom"
```

多引号多数用于在py文件内编辑解释的文档，因为可以支持换行

### 转义字符
Python经常需要表示特殊功能或特殊字符，如响铃
但是Python没有专门用来描述这类特殊功能或特殊字符的字符，就需要使用转义字符

转义字符通过符号`\`+普通字符来表达特定符号或功能
`\`在之前的逻辑行时用来表示续行，但在字符串里表示转义

Python使用的转义字符对应相关功能与特殊符号如下

| 转义           | 功能               |
| ------------ | ---------------- |
| `\`<newline> | 忽略反斜杠与换行符        |
| `\\`         | 反斜杠（`\`）         |
| `\'`         | 单引号（`'`）         |
| `\"`         | 双引号（`"`）         |
| `\a`         | ASCII 响铃（BEL）    |
| `\b`         | ASCII 退格符（BS）    |
| `\f`         | ASCII 换页符（FF）    |
| `\n`         | ASCII 换行符（LF）    |
| `\r`         | ASCII 回车符（CR）    |
| `\t`         | ASCII 水平制表符（TAB） |
| `\v`         | ASCII 垂直制表符（VT）  |
| `\_ooo_`     | 八进制数 _ooo_ 字符    |
| `\x_hh_`     | 十六进制数 _hh_ 字符    |
如
```python
# 转义特殊符号
'I\'m Tom'

# 转义特殊功能
"listen, the call is ringing\a"
```

### 原始字符串
当不需要转义字符但是字符串中存在`\`时，要确保没有转义字符存在，使用前缀`r`或`R`，这称为**原始字符串**
如
```python
# 表示原始字符串
r"I'm a coder\a"
R"I'm a coder\a"
```

Python会解释为
```python
I'm a coder\a
```

### 字节串
字符串是人可读的**文本**，字节串是机器读的**二进制数据**
字节串一般用于图片或视频文件或者网络传输文件

字节串并没有单独拿出一节来说，因为字节串与字符串是类似的

字节串是在字符串之前加上前缀`b`
如
```python
# 表示字节串
b"this is byte"
b'this is byte'
b"""this is byte"""
```

字节串同样支持转义字符
如
```python
# 字节串转义特殊功能
b"listen, the call is ringing\a"
```

字节串同样拥有原始字节串(Raw Bytes)，使用`rb`或`br`
如
```python
# 表示原始字节串
rb"this is byte\a"
br"this is byte\a"
```

# 逻辑值
逻辑值就是**真**和**假**两个概念，用符号表示就是：
- 真（True）
- 假(False)

逻辑值可以用作
- **判断的结果**
- **决策的依据**
如5大于3，逻辑值为**真**（判断的结果）；如果今天下雨为真，就不出门（决策的依据）

字面值中：
- **不为0**的数字（包括整数、浮点数、虚数）逻辑值都为真，反之为假
- 字符串只要不为空字符串，即`''`或`""`与`""""""`，逻辑值都为真，反之为假
