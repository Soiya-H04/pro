#变量 
## 变量

---
### 一、概念

#### 1.1 用途

变量是指用来存储数据的量，其值能够被改变
#### 1.2 类型

变量类型对应数据类型
#### 1.3 存储空间

变量所使用的**存储空间**为数据类型规定的**存储空间**
单个变量使用的内存单元的内存地址**连续**
### 二、使用
#### 2.1 声明

声明变量的语法为
```c
数据类型 变量名;
```

可以同时声明多个**同类型**变量

同时声明多个同类型变量的语法为
```c
数据类型 变量名1, 变量名2,···;
```
#### 2.2 初始化

不初始化变量会存储**不确定值**
推荐在声明变量时进行初始化
初始化**不符合**数据类型的值，参照[[Data Type#5.4 转换规则|转换规则]]

初始化变量的语法为
```c
数据类型 变量名 = 值;
数据类型 变量名1 = 值1, 变量名2 = 值2, 变量名3 = 值3, ···;
```
#### 2.3 赋值

变量赋予**不符合**数据类型的值，参照[[Data Type#5.4 转换规则|转换规则]]

简单赋值的语法为
```c
变量名 = 值;
```

除了使用简单赋值，
还能根据需要[[Operator#复合赋值|复合赋值]]
#### 2.4 常变量

常变量指只能**初始化**，不能进行**赋值**的变量
常变量可以通过**其他方式**赋值
常变量使用[[Keywords|关键字]]`const`

初始化常变量的语法为
```c
const 数据类型 常变量名 = 值;
```
#### 2.5 静态变量

静态变量指在整个程序里只会**声明并初始化一次**的变量

声明静态变量的语法为
```c
static 数据类型 静态变量名;
```

初始化静态变量的语法为
```c
static 数据类型 静态变量名 = 值;
```

赋值静态变量的语法为
```c
静态变量名 = 值;
```

----
### 三、限制
#### 3.1 全局变量与局部变量

变量根据声明区域被分为**全局变量**与**局部变量**；局部变量进一步可以分为**外部变量**与**内部变量**
全局变量声明在主函数的外部，局部变量声明在主函数内部；在主函数内，外部变量与内部变量，按照`{}`来划分
#### 3.2 使用优先级

全局变量与局部变量，外部变量与内部变量可以同名
使用变量时存在**优先级**： 在同一个`{}`里，同名内部变量 > 外部变量 > 全局变量
#### 3.3 作用域

作用域是变量能够被使用的区域
全局变量可以在程序的**全部区域**使用；局部变量只能在**声明变量的`{}`内**使用
同程序的源文件引用**其他源文件**声明的全局变量使用[[Keywords|关键字]]`extern`

引用全局变量的语法为
```c
extern 数据类型 全局变量名;
```

**静态全局变量**只能在声明的源文件中使用

### 四、指针变量

#### 4.1 用途

指针变量是存储指针的变量
#### 4.2 声明

指针变量的类型对于变量类型

声明指针变量的语法为
```c
数据类型* 指针变量;
```

可以同时声明多个**同类型**的指针变量

同时声明多个指针变量的语法为
```c
数据类型* 指针变量1,* 指针变量2,* 指针变量3, ···;
```
#### 4.3 初始化

初始化指针变量一般使用操作符`&`，一般用变量

初始化指针变量的语法为
```c
数据类型* 指针变量 = &变量;
```

可以同时初始化**同类型**的指针变量

同时初始化多个指针变量的语法为
```c
数据类型* 指针变量1 = &变量1,* 指针变量2 = &变量2,* 指针变量3 = &变量3, ···;
```

指针变量**必须初始化**，否则会出现**野指针**（地址不确定的指针）
无明确地址时，可以初始化为空指针(`NULL`)

初始化空指针的语法为
```c
数据类型* 指针变量 = NULL;
```
#### 4.4 常指针

常指针是指针变量的某些值不能改变
常指针使用关键字`const`
##### a. 常值

指针变量的**地址指向值**不能改变

限制指针变量为常值的语法为
```c
const 数据类型* 指针变量名 = 值;
```
##### b. 常址

指针变量的**存储地址**不能改变

限制指针变量为常址的语法为
```c
数据类型* const 指针变量名 = 值;
```
##### c. 常值常址

指针变量的**存储地址**与**地址指向值**不能改变

限制指针变量为常值常址的语法为
```c
const 数据类型* const 指针变量名 = 值;
```
#### 4.5 大小

指针格式**固定**为**十六进制**
在 32 位系统中指针变量的大小固定为 **8 字节**
操作符`sizeof()`可以获得指针变量类型相应的大小

获得指针变量类型大小的语法为
```c
sizeof(指针变量类型);
```
#### 4.6 使用

可以通过解引用（`*`）与下标引用（`[]`）来使用与改变指针变量地址里的值

通过解引用使用、修改指针变量的语法为
```c
*指针变量;
*指针变量 = 值;
```

通过下标引用使用、修改指针变量的语法为
```c
指针变量[0];
指针变量[0] = 值;
```

解引用、下标引用会使用指针变量**对应数据类型大小**的存储空间
