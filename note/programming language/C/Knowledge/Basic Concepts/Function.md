#函数 #C 
## 函数
---
### 一、函数概念
#### 1.1 声明

头文件内声明函数

声明函数的语法为
```c
返回值类型 函数名(参数);
```
#### 1.2 存储方式

声明、定义函数时不会开辟内存空间
调用函数时，会**开辟内存空间**供函数使用
#### 1.3 组成

函数头（**返回值类型**、**函数名**、**参数**）与函数体（**具体代码**）
#### 1.4 返回值

返回值类型可为**常量**、**变量**、**结构体**、**函数**、**枚举**等
使用返回值在**函数末尾**使用关键字`return`
`void`返回值类型无返回值

使用返回值语法为
```c
return 返回值;
```
#### 1.5 主函数

程序入口
一个程序**只有一个**主函数

主函数的语法为
```c
int main()
{
	return 0;
}
```
#### 1.6 调用

调用函数使用操作符`()`，结果为返回值

调用无参函数的语法为
```c
函数名();
```

调用有参函数的语法为
```c
函数名(参数);
```

### 二、传参
#### 2.1 值传参

值传参将实参值**复制传递**给形参
形参和实参是**相互独立**的变量，占用**不同的内存空间**
实参为变量、常量、结构体等**非地址值**
值传参**不影响**实参

使用值传递的语法为
```c
返回值类型 函数名(参数类型1 形参名1, 参数类型2 形参名2, ···);
```
#### 2.2 地址传参

地址传参将**实参地址**传递给形参
形参通过实参地址**访问和改变**实参值
实参为变量、常量、数组、结构体、函数等对象的**地址**
地址传参**影响**实参

使用地址传递的语法为
```c
返回值类型 函数名(参数类型1* 形参名1, 参数类型1* 形参名1, ···);
```
#### 2.3 数组传参

数组传参为**地址传参**，可以**改变**数组值
##### a. 一维数组

传递参数为一维数组**首元素地址（`数组名`）**
**固定数组长度**在函数内直接使用**预定义数组长度**

传固定一维数组的语法为
```c
返回值类型 函数名(元素类型 形参名[数组长度]);
```

**不固定数组长度**需要额外传递**数组长度**

传不固定一维数组的语法为
```c
返回值类型 函数名(元素类型 形参名[], 数据类型 数组长度);
```

**指针变量**可以传**一维数组首元素地址**，需要额外传递**数组长度**

使用指针变量传不固定一维数组的语法为
```c
返回值类型 函数名(元素类型* 指针变量名, 数据类型 数组长度);
```
##### b. 二维数组

传递参数为二维数组**首行元素地址（`数组名`）**
**固定数组行数、列数**在函数内直接使用**预定义数组行数、列数**

传固定二维数组的语法为
```c
返回值类型 函数名(元素类型 形参名[数组行数][数组列数]);
```

**不固定数组行数**需要额外传递**数组行数**

传不固定二维数组的语法为
```c
返回值类型 函数名(元素类型 形参名[][数组列数], 数据类型 数组行数);
```

**数组指针**可以传**二维数组首行元素地址**，需要额外传递**数组行数**

使用数组指针传不固定二维数组的语法为
```c
返回值类型 函数名(元素类型 (* 数组指针)[数组列数], 数据类型 数组行数);
```
#### 2.4 传参限制

传参限制跟变量里的**常指针**与**常变量**用途相同

在函数传参中使用常变量的语法为
```c
返回值类型 函数名(const 数据类型 形参名);
```

在函数传参中使用常值指针变量的语法为
```c
返回值类型 函数名(const 数据类型* 形参名);
```

在函数传参中使用常址指针变量的语法为
```c
返回值类型 函数名(数据类型* const 形参名);
```

在函数传参中使用常值常址变量的语法为
```c
返回值类型 函数名(const 数据类型* const 形参名);
```l
