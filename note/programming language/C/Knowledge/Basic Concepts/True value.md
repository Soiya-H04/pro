#真值 #条件判断
##  真值
---
### 一、概念

#### 1.1 定义

日常生活中，一个事件通常只有两种情况：**发生**或**未发生**
可以抽象视作这个事件**发生时逻辑为真**，**不发生时逻辑为假**
在计算机中，就是用**真值**来表示事件逻辑的值
#### 1.2 取值

| 真值  | 符号    |
| --- | ----- |
| 真   | true  |
| 假   | false |
#### 1.3 逻辑判断

判断规则：**非零值为真，零值为假**

| 真值  | 描述               | 字符                 | 数值  |
| --- | ---------------- | ------------------ | --- |
| 真   | 任何非零值都表示逻辑“真”    | 非`'\0'`，ASCII 码非 0 | 非 0 |
| 假   | 任何零值都表示逻辑“假”<br> | `'\0'`，ASCII 码为 0  | 0   |
