#C #操作符
## 操作符

---
#### 一、算术操作符

| 算术操作符 | 描述                                              |
| :---: | ----------------------------------------------- |
|  `+`  | 加法操作                                            |
|  `-`  | 减法操作                                            |
|  `*`  | 乘法操作                                            |
|  `/`  | 除法操作<br>两个表达式的值为整型时，为整除<br>有一个表达式的值为浮点数时，结果为浮点数 |
|  `%`  | 求模操作<br>表达式的值只能为整型<br>当第一个表达式的值为负数时，结果为负数       |
### 二、移位操作符

| 移位操作符  | 描述                                  |
| :----: | ----------------------------------- |
| `>> n` | 右移操作，将表达式值的二进制数右移 n 位（n 为正整数），高位补 0 |
| `<< n` | 左移操作，将表达式值的二进制数左移 n 位（n 为正整数），低位补 0 |

### 三、位操作符

| 位操作符 | 描述   |
| :--: | ---- |
| `&`  | 按位与  |
| `^`  | 按位异或 |
|  \|  | 按位或  |
| `~`  | 取反   |

### 五、自操作符

| 自操作符 | 描述                   |
| :--: | -------------------- |
| `--` | --a 前置自减<br>a-- 后置自减 |
| `++` | ++a 前置自加<br>a++ 后置自加 |
### 六、关系操作符

| 关系操作符 |
| :---: |
|  `>`  |
|  `<`  |
| `==`  |
| `<=`  |
| `>=`  |
| `!=`  |
>注意：
>比较字符时，比较字符的 ASCII 码
  关系操作符不能比较字符串

>推荐:
>比较变量与常量时
>将变量放在右边，常量放在左边，可以防止写为赋值操作符`=
### 七、逻辑操作符

| 逻辑操作符 |
| :---: |
|  `!`  |
| `&&`  |
| \|\|  |
>短值处理：
>`&&`当左表达式为 false，右值不计算；`||` 当左表达式为 true，右值不计算
### 八、条件操作符

| 条件操作符            | 描述                                  |
| ---------------- | ----------------------------------- |
| `exp1?exp2:exp3` | exp1 为真，为 exp2 的值；exp1 为假，为 exp3 的值 |
### 九、其他操作符
