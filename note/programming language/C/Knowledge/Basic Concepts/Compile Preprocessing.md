## 编译预处理

---
### 一、概念

#### 1.1 预处理指令

使用预处理指令的语法为
```c
#预处理指令
```
#### 1.2 文件包含

预处理指令`#include`将其他文件内容包含到当前文件中
包含头文件的语法见[[Files#三、文件包含|文件包含]]
#### 1.3 定义无参宏

定义无参宏定义的语法为
```c
#define 标识符 常量
```
#### 1.4 含参宏定义

预处理指令`#define`可以定义含参宏

使用含参宏定义的语法为
```c
#define A标识符(参数 1,参数 2, ···) 参数表达式
```

#### 1.5 条件编译

| 基本条件编译指令 | 描述                                |
| -------- | --------------------------------- |
| `#if`    | 后接的常量表达式为真进行编译<br>后接的常量表达式为假不进行编译 |
| `#elif`  | 后接的常量表达式为真进行编译<br>后接的常量表达式为假不进行编译 |
| `#else`  | 当前面的条件都为假时进行编译                    |
| `#endif` | 结束条件编译                            |
使用基本条件编译指令的语法为
```c
#if 常量表达式_1
    
#elif 常量表达式_2
    
#else
    
#endif
```

| 条件编译宏指令   | 描述            |
| --------- | ------------- |
| `#ifndef` | 后接的宏没有被定义进行编译 |
| `#ifdef`  | 后接的宏被定义进行编译   |
使用条件编译宏指令的语法为
```c
#ifndef 宏_1
	
#endif
#ifdef 宏_2
	
#endif
```
