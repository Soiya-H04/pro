#C #数据类型

## 数据类型

---
### 一、概念
#### 1.1 定义

数据类型是计算机**预先定义**的[[Keywords|关键字]]
#### 1.2 分类

数据类型分为三大类

| 数据类型 |
| ---- |
| 整型   |
| 浮点型  |
| 字符型  |
#### 1.3 使用

数据类型用于声明变量
### 二、整型

#### 2.1 定义

整型表示整数
#### 2.2 类型

整型被分为三种类型

|     整型      |
| :---------: |
|   `short`   |
|    `int`    |
|   `long`    |
| `long long` |

#### 2.3 符号

**有符号整型(`signed`)**能够表示负整数；**无符号整型(`unsigned`)**只能够表示正整数
整型默认为**有符号整型**，可以省略`signed`

|         有符号整型          |      无符号整型       |
| :--------------------: | :--------------: |
| `signed short`/`short` | `unsigned short` |
|   `signed int`/`int`   |  `unsigned int`  |
|  `signed long`/`long`  | `unsigned long`  |
#### 2.4 存储空间

|  有符号整型  |  存储空间  |         存储整数范围          |      无符号整型       |  存储空间  |      存储整数范围       |
| :-----: | :----: | :---------------------: | :--------------: | :----: | :---------------: |
| `short` | 2 Byte | $-2^{15} \sim 2^{15}-1$ | `unsigned short` | 2 Byte | $0\sim 2^{16}-1$  |
|  `int`  | 4 Byte | $-2^{31} \sim 2^{31}-1$ |  `unsigned int`  | 4 Byte | $0 \sim 2^{32}-1$ |
| `long`  | 4 Byte | $-2^{31} \sim 2^{31}-1$ | `unsigned long`  | 4 Byte | $0 \sim 2^{32}-1$ |

#### 2.5 存储方式

整型存储整数二进制的[[Storage code#1.4 补码|补码]]，格式为[[Storage code#1.1 进制|十六进制]]
整型符号由一个 **bit** 位表示，称为**符号位**
有符号整型**第一个 bit** 位（最高位）为符号位，其余 **bit** 位**由高到低**存储补码
无符号整型的所有 **bit** 位**由高到低**存储补码

---
### 三、浮点型

#### 3.1 定义

浮点型表示浮点数
#### 3.2 类型

浮点型被分为两个类型

|   浮点型    |        描述         |
| :------: | :---------------: |
| `float`  | 单精度浮点型，有效小数为 7 位  |
| `double` | 双精度浮点型，有效小数为 15 位 |
#### 3.3 符号

浮点型都为有符号浮点型
#### 3.4 存储空间

|   浮点型    |  存储空间  |                                    存储浮点数范围                                     |
| :------: | :----: | :----------------------------------------------------------------------------: |
| `float`  | 4 Byte |   正数：$3.4*10^{-38} \sim 3.4*10^{38}$<br>负数：$-3.4*10^{-38} \sim -3.4*10^{38}$   |
| `double` | 8 Byte | 正数：$1.7*10^{-308} \sim 1.7*10^{308}$<br>负数：$-1.7*10^{-308} \sim -1.7*10^{308}$ |
#### 3.5 存储方式

浮点型存储浮点数的[[Storage code#1.5 浮点数二进制|浮点码]]，格式为[[Storage code#1.1 进制|十六进制]]
浮点型第一个 **bit** 位为符号位，其余 **bit** 位存储阶码与尾数

|   浮点型    | 尾数位 | 阶码位 |
| :------: | :-: | :-: |
| `float`  |  8  | 23  |
| `double` | 11  | 52  |

---
### 四、字符型

#### 4.1 定义

字符型表示字符
常用字符以及对应数值见 [[ASCII code|ASCII]]
字符型实际存储的为字符的 ASCII 码（**整型数据**）
#### 4.2 类型

字符型只有一种类型

|  字符型   |
| :----: |
| `char` |
#### 4.3 符号

字符型存储字符的 **ASCII 码**，也使用符号来表示正负
**有符号字符型（`signed`）**能够表示负整数；**无符号字符型（`unsigned`）**只能够表示正整数
字符型默认为**有符号字符型**，可以省略`signed`

|        有符号字符型        |     无符号字符型      |
| :------------------: | :-------------: |
| `signed char`/`char` | `unsigned char` |
#### 4.4 存储空间

| 有符号字符型 |  存储空间  |        存储整数范围         | 无符号字符型          |  存储空间  |      存储整数范围      |
| :----: | :----: | :-------------------: | --------------- | :----: | :--------------: |
| `char` | 1 Byte | $-2^{7} \sim 2^{7}-1$ | `unsigned char` | 1 Byte | $0 \sim 2^{8}-1$ |
#### 4.5 存储方式

字符型存储字符的 ASCII 码（整数）二进制的[[Storage code#1.3 补码|补码]]，格式为[[Storage code#1.1 进制|十六进制]]
有符号字符型第一个 **bit** 位（最高位）为符号位，其余 **bit** 位**由高到低**补码
无符号字符型所有 **bit** 位都**由高到低**补码

### 五、类型转换

#### 5.1 定义

类型转换指将已经存储的数据的数据类型转换为另一种数据类型
#### 5.2 隐式转换

隐式转换是计算机**自动进行**的类型转换（创建副本）
隐式转换分为**操作转换**与**赋值转换**

操作转换指使用操作符时，会将**存储范围较小**的数据类型转换为**存储范围较大**的数据类型，结果为两个相同的**存储范围大**的数据类型进行操作（**不会丢失数据精度**）

赋值转换指给变量赋值不符合其声明的数据类型的值，根据变量的数据类型进行转换，再赋值给变量（**可能会丢失数据精度，甚至会出错**）
#### 5.3 强制转换

强制转换是指**手动转换**数据类型（创建副本）
强制转换需要将转换结果赋值给相应数据类型的变量
强制转换使用操作符`(数据类型)`

使用强制转换的语法为
```c
(数据类型)值
```
#### 5.4 转换规则

类型转换遵守**转换规则**：
1. **字符型**、**整型**转换为**浮点型**
>添加**小数部分**（后面添 0）
2. **字符型**转换为**整型**
>值不变
3. **整型**转换为**字符型**
>整数没有超过字符型存储空间，值不变；超过**值错误**
4. **浮点型**转换为**字符型、整型**
>值没有超过字符型或整型存储空间，截去小数部分，保留整数部分；超过**值错误**
