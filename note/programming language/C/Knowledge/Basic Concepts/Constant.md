#C #常量 
## 常量

---
### 一、概念

#### 1.1 定义

在 C 语言中，常量是指值不能被改变的量
#### 1.2 类型

在 C 语言中，常量分为四种类型

| 常量    |
| ----- |
| 整型常量  |
| 浮点型常量 |
| 字符常量  |
| 字符串常量 |
### 二、整型常量

#### 2.1 定义

整数
#### 2.2 使用

使用整数的[[Storage code#1.1 进制|十进制、八进制、十六进制]]

| 进制   | 表示方式     |
| ---- | -------- |
| 八进制  | 以数字 0 开头 |
| 十进制  | 正常数字     |
| 十六进制 | 以 0x 开头  |

---
### 三、浮点型常量

#### 3.1 定义

浮点数
#### 3.2 使用

使用浮点数的[[Storage code#1.1 进制|十进制]]来表示，其表示形式可为**小数形式**与**指数形式**

| 浮点型形式 | 表示方式                                    |
| ----- | --------------------------------------- |
| 小数形式  | 由 0-9 与小数点组成                            |
| 指数形式  | 由尾数、`e`、指数三部分组成<br>尾数可为整数或小数<br>指数必须是整数 |

浮点型常量默认使用`double`
使用`float`型的精度，在**常量末尾**加`f`

---
### 四、字符常量

#### 4.1 定义

字符，用**单引号**括起
#### 4.2 使用

常见字符见 [[ASCII code|ASCII]]
**可打印字符**用单引号括起表示
**控制字符**用**转义字符**表示
转义字符以**反斜杠 `\`** 开头

| 常用转义字符 | 描述                        |
| ------ | ------------------------- |
| `\n`   | 换行符                       |
| `\t`   | 水平制表符（Tab）                |
| `\r`   | 回车符                       |
| `\b`   | 退格符                       |
| `\f`   | 换页符                       |
| `\\`   | 反斜杠                       |
| `\'`   | 单引号                       |
| `\"`   | 双引号                       |
| `\?`   | 问号                        |
| `\a`   | 警报（响铃）                    |
| `\v`   | 垂直制表符                     |
| `\ddd` | 1 到 3 位八进制 ASCII 码值表示的字符  |
| `\xhh` | 1 到 2 位十六进制 ASCII 码值表示的字符 |

---
### 五、字符串常量

#### 5.1 定义

字符串，用**双引号**括起
#### 5.2 使用

字符串常量实际就是**单个或多个字符常量**按序列组成，并在**末尾**添加`'\0'`作为字符串的**结束标志**（`'\0'`不显示）
