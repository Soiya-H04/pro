#C  #标识符 
## 标识符
---
### 一、命名限制

#### 1.1 首字符限制

标识符的首字符必须是字母`A-Z`或`a-z`或下划线`_`，不能以数字`0-9`开头
#### 1.2 后续字符限制

标识符的后续字符可以是字母`A-Z`或`a-z`、下划线`_`、数字`0-9`
#### 1.3 大小写敏感限制

C  语言中的大小写敏感
#### 1.4 关键字限制

标识符不能是C语言的[[Keywords|关键字]]

---
### 二、命名规范
#### 2.1 变量名

变量名字符全小写
#### 2.2 函数名

函数名首字符大写
#### 2.3 类型名

类型（结构体、枚举）名单词首字符大写
#### 2.4 宏名

宏名字符全大写
