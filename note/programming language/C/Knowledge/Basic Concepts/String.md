## 字符串
---
### 一、概念
#### 1.1 组成

字符串是由零个或多个字符组成的有限序列
#### 1.2 结束标志

字符串以空字符`'\0'`作为结束标志
#### 1.3 声明

字符串以`""`括起
##### a. 字符数组

使用字符数组声明字符串，值可以按照数组赋值方式更改

使用字符数组声明字符串的语法为
```c
char 字符串名[数组长度] = 字符串;
```

数组长度需要**大于等于**字符串字符个数 + 1
字符串多出来的部分使用`'\0'`填充

不指定数组长度声明字符串的语法为
```c
char 字符串名[] = 字符串;
```

会默认多存储一个`'\0'`作为结束标志
##### b. 字符指针

使用字符指针声明字符串，值不能更改

使用字符数组声明字符串的语法为
```c
char* 字符串名 = 字符串;
```
