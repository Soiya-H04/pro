## 结构体
---
### 一、概念
#### 1.1 用途

结构体将一组**不同类型**的成员组合储存
#### 1.2 成员

结构体的成员可以为基本数据类型、数组、其他结构体、指针等
#### 1.3 大小

结构体大小遵循字节对齐规则：
1. 成员开始地址为**自身对齐数对应地址**
2. 结构体开始地址为**最大成员对齐数对应地址**

---
### 二、使用
#### 2.1 定义
##### a. 一般结构体

定义一般结构体的语法为
```c
struct 结构体名 {
    成员类型1 成员1;
    成员类型2 成员2;
    ...
};
```
##### b. 重命名结构体

重命名结合体使用**类型重命名**关键字`typedef`

定义重命名结构体的语法为
```c
typedef struct 结构体名 {
    成员类型1 成员1;
    成员类型2 成员2;
    ...
} 重命结构体名;
```

`struct 结构体名`与`重命名结构体名`是同个结构体
##### c. 匿名重命名结构体

匿名结构体**不定义结构体名**，直接定义重命名结构体名

定义匿名重命名结构体的语法为
```c
typedef struct {
    成员类型1 成员1;
    成员类型2 成员2;
    ...
} 重命结构体名;
```


#### 2.2 位域（谨慎使用）

位域用于控制结构体成员占用的**内存位数（bit）**，而不是**默认字节数（byte）**
位域会有**编译器差异**

使用位域的语法为
```c
typedef struct {
    成员类型1 成员1 : 占位数1;
    成员类型2 成员2 : 占位数2;
    ...
} 重命结构体名;
```

>限制：
>不能对位域成员使用取地址运算符 `&`
>不能创建位域数组
#### 2.3 声明
##### a. 一般结构体

声明一般结构体变量的语法为
```c
struct 结构体名 结构体变量名;
```

声明多个一般结构体变量的语法为
```c
struct 结构体名 结构体变量名1, 结构体变量名2, ···;
```
##### b. 重命名结构体
 
声明重命名结构体变量的语法为
```c
重命名结构体名 结构体变量名;
```

声明多个重命名结构体变量的语法为
```c
重命名结构体名 结构体变量名1, 结构体变量名2, ···;
```

也可以使用一般结构体变量的语法声明
##### c. 匿名重命名结构体

只能使用重命名结构体变量的语法声明

#### 2.4 初始化

初始化结构体变量**按照顺序**赋值

初始化结构体变量的语法为
```c
重命名结构体名 结构体变量名 = {值1, 值2, ···};
```
#### 2.5 指针

声明结构体类型的指针变量语法为
```c
重命名结构体名* 指针变量名;
```

给指针变量赋予结构体地址的语法为
```c
重命名结构体名* 指针变量名 = &结构体变量名;
```
#### 2.6 访问成员

访问结构体变量的成员有两个语法：使用操作符`.`通过**结构体变量**进行成员访问、使用操作符`->`通过**结构体变量地址**进行成员访问

使用`.`访问结构体变量成员的语法为
```c
结构体变量.成员名;
```

使用`->`访问结构体变量成员的语法为
```c
结构体变量地址->成员名;
```
#### 2.7 数组

结构体数组存储**相同类型结构体**

声明结构体一维数组的语法为
```c
重命名结构体名 结构体数组名[数组长度];
```

声明结构体二维数组的语法为
```c
重命名结构体名 结构体数组名[数组行数][数组列数];
```
#### 2.8 赋值

赋值一般类型成员的语法为
```c
结构体变量名.成员名 = 值;
```

赋值字符串类型成员的语法为
```c
strcpy(结构体变量名.成员名, "字符串");
```
