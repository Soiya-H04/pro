#C #数组 #数据类型 
## 数组

---
### 一、概念

#### 1.1 定义

数组存储一组**相同数据类型**的元素
#### 1.2 存储

数组中元素存储在**地址连续**的内存空间，由**低地址向高地址**依次存储
#### 1.3 元素下标

元素有**唯一**下标，按照顺序下标由`[0]`依次递增
#### 1.4 一维数组

一维数组的元素下标为一层`[]`
#### 1.5 二维数组

二维数组的元素下标为两层`[][]`
二维数组**本质为一维数组**，元素为一维数组
#### 1.6 元素类型

元素类型可以为**基础数据类型**、**结构体**、**枚举**
### 二、定义
#### 2.1 一维数组

定义一维数组的语法为
```c
袁旭类型 数组名[数组长度];
```

初始化一维数组的语法为
```c
元素类型 数组名[数组长度] = {元素1,元素2,元素3,···};
```

用一维数组初始化一维数组的语法为
```c
元素类型 数组名[数组长度] = 一维数组;
```

初始化**少于**数组长度的元素，元素由`[0]`开始的下标顺序放在数组中，其余位置补上**默认填补元素**

| 数据类型 | 默认填补元素 |
| ---- | ------ |
| 数值   | 0      |
| 字符   | '0'    |
| 字符串  | '\0'   |
省略数组长度会通过**初始化的元素个数**进行初始化

初始化一维数组并省略数组长度的语法为
```c
元素类型 数组名[] = {元素1,元素2,元素3,···};
```
#### 2.2 二维数组

定义二维数组的语法为
```c
元素类型 数组名[行数][列数];
```

初始化二维数组的语法为
```c
元素类型 数组名[行数][列数] = {
{行1列1元素,行1列2元素,行1列3元素,···},
{行2列1元素,行2列2元素,行2列3元素,···},
{行3列1元素,行3列2元素,行3列3元素,···},
···
};
```

用二维数组初始化二维数组的语法为
```c
元素类型 数组名[行数][列数] = 二维数组名;
```

初始化少于数组行数、列数的元素，元素由行到列放在数组中，其余位置补上**默认填补元素**

**省略行数**会通过**列数**进行初始化

初始化二维数组并省略行数的语法为
```c
元素类型 数组名[][列数] = {
{行1列1元素,行1列2元素,行1列3元素,···},
{行2列1元素,行2列2元素,行2列3元素,···},
{行3列1元素,行3列2元素,行3列3元素,···},
···
};
```
### 三、类型与大小
#### 3.1 数组类型

数组类型为元素类型加`[]`
#### 3.2 数组大小
##### a. 一维数组

`sizeof(数组名)`：**总数组大小**
`sizeof(数组名[0])`：**单元素大小**
`sizeof(&数组名)`：**地址大小**
##### b. 二维数组

`sizeof(数组名)`：**总数组大小**
`sizeof(&数组名)`：**地址大小**
`sizeof(数组名[0])`：**单行元素大小**
`sizeof(数组名[0][0])`：**单元素大小**
### 四、使用
#### 4.1 访问元素

两种方法：解引用（`*`）、下标引用（`[]` ）

访问一维数组元素的语法为
```c
一维数组名[元素下标];
*(一维数组名 + 元素下标);
```

访问二维数组元素的语法为
```c
二维数组名[元素行下标][元素列下标]
*(*(二维数组名 + 元素行下标) + 元素列下标);
```
#### 4.2 遍历数组

遍历一维数组需要**数组长度**
遍历二维数组需要**行数**与**列数**

获得一维数组数组长度的语法为
```c
数组长度 = sizeof(数组名) / sizeof(数组名[0]);
```

获得二维数组的行数的语法为
```c
行数 = sizeof(数组名) / sizeof(数组名[0]);
```

获得二维数组的列数的语法为
```c
列数 = sizeof(数组名[0]) / sizeof(数组名[0][0]);
```

使用 for 语句遍历一维数组的语法为
```c
for(int i = 0;i < 数组长度;i++)
{
	元素 = 数组名[i];
	元素 = *(一维数组名 + 元素下标);
}
```

使用 for 语句遍历二维数组的语法为
```c
for(int i = 0;i < 行数;i++)
{
	for(int j = 0;j < 列数;j++)
	{
		元素 = 数组名[i][j];
		*(*(二维数组名 + 元素行下标) + 元素列下标);
	}
}
```

使用 while 语句遍历一维数组的语法为
```c
int i = 0;
while(i < 数组长度)
{
	元素 = 数组名[i];
	元素 = *(一维数组名 + 元素下标);
	i++;
}
```

使用 while 语句遍历二维数组的语法为
```c
int i = 0;
int j = 0;
while(i < 行数)
{
	while(j < 0)
	{
		元素 = 数组名[i][j];
		*(*(二维数组名 + 元素行下标) + 元素列下标);
		j++;
	}
	i++;
}
```
#### 4.3 修改

修改一维数组元素的语法为
```c
数组名[元素下标] = 值;
*(一维数组名 + 元素下标) = 值;
```

修改二维数组元素的语法为
```c
数组名[元素行下标][元素列下标] = 值;
*(*(二维数组名 + 元素行下标) + 元素列下标) = 值;
```
#### 4.4 地址
##### a. 一维数组

| 语法         | 地址                                |
| ---------- | --------------------------------- |
| `数组名`      | 数组**首元素地址**                       |
| `数组名 + 1`  | 数组**第二个元素地址**，+1 等于 +元素大小         |
| `&数组名`     | 数组**首地址**                         |
| `&数组名 + 1` | 数组**尾元素地址 + 1**，+1 等于 +元素大小\*数组长度 |
解引用、下标引用一维数组**首地址**得到数组**首元素地址**

解引用、下标引用一维数组首地址得到数组首元素地址的语法为
```c
*(&数组名);
(&数组名)[0];
```
##### b. 二维数组

| 语法         | 地址                                      |
| ---------- | --------------------------------------- |
| `数组名`      | 数组**首行元素地址**                            |
| `数组名 + 1`  | 数组**第二行元素地址**，+1 等于+元素大小*数组列数           |
| `&数组名`     | 数组**首地址**                               |
| `&数组名 + 1` | 数组**尾元素地址 + 1**，+1 等于 +元素大小\*数组行数\*数组列数 |
解引用、下标引用二维数组**首地址**得到数组**首行元素地址**

解引用、下标引用二维数组首地址得到数组首行元素地址的语法为
```c
*(&数组名);
(&数组名)[0];
```

### 五、数组指针
#### 5.1 定义

数组指针存储数组**首地址**

定义一维数组指针的语法为
```c
元素类型 (* 一维总数组指针名) [数组长度] = &一维数组名;
```

定义二维数组指针的语法为
```c
元素类型 (* 二维总数组指针名) [行数][列数] = &二维数组名;
```
#### 5.2 使用
##### a. 一维数组

解引用、下标引用一维数组**首地址**得到数组**首元素地址**

解引用、下标引用一维数组首地址得到数组首元素地址的语法为
```c
*数组指针;
数组指针[0];
```

通过一维数组指针访问数组元素的语法为
```c
*(*数组指针 + 元素下标);
数组指针[0][元素下标];
```

通过一维数组指针修改数组元素的语法为
```c
*(*数组指针 + 元素下标) = 值;
数组指针[0][元素下标] = 值;
```

##### b. 二维数组

解引用、下标引用二维数组**首地址**得到数组**首行元素地址**

解引用、下标引用二维数组首地址得到数组首行元素地址的语法为
```c
*数组指针;
数组指针[0];
```

通过二维数组指针访问数组元素的语法为
```c
*(*(*数组指针 + 元素行下标) + 元素列下标);
数组指针[0][元素行下标][元素列下标];
```

通过二维数组指针修改数组元素的语法为
```c
*(*(*数组指针 + 元素行下标) + 元素列下标) = 值;
数组指针[0][元素行下标][元素列下标] = 值;
```

### 六、指针数组
#### 6.1 定义

指针数组是存放指针的数组

定义一维指针数组的语法为
```c
元素类型* 一维指针数组名[数组长度];
```

定义二维指针数组的语法为
```c
元素类型* 二维指针数组名[数组行数][数组列数];
```
#### 6.2 初始化

初始化指针数组语法与初始化数组语法一致
#### 6.3 使用

访问一维指针数组元素的值的方法为
```c
一维指针数组名[元素下标][0];
*(一维指针数组名 + 元素下标);
```

访问二维指针数组元素的值的方法为
```c
二维指针数组名[元素行下标][行数列下标][0];
*(*(二维指针数组名 + 元素行下标) + 元素列下标)
```
