## 枚举
---
### 一、概念
#### 1.1 作用

枚举为**一组整数**值赋予有意义的名称
#### 1.2 定义

定义枚举有两种方式：**显式指定**、**默认值**
默认值的枚举常量从 0 开始

定义默认值的枚举类型的语法为
```c
enum 枚举名 {
    枚举常量1, // 0
    枚举常量2, // 1
    ...
    枚举常量n // n
};
```

定义显式指定的枚举类型的语法为
```c
enum 枚举名 {
    枚举常量1 = 整数1,
    枚举常量2 = 整数2,
    ...
    枚举常量n = 整数n
};
```

>可以接受部分显式指定，其余按顺序指定
#### 1.3 使用

使用枚举常量的语法为
```c
enum 枚举名 枚举常量名 = 枚举常量;
```

>枚举常量**不是变量**，不能对其**赋值**
