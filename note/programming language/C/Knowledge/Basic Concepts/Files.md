
#C #源文件 #头文件 #主函数

---
### 一、源文件

#### 1.1 概念

源文件是用来存放**程序具体代码**的文件
#### 1.2 拓展名

源文件的拓展名为 .c
#### 1.3 程序可容纳源文件数

一个程序理论上可以有无限个**不重名**的源文件

---
### 二、头文件

#### 2.1 概念

头文件是存放**同名源文件**的相关内容（函数声明、全局变量定义等）的文件
#### 2.2 拓展名

头文件的拓展名为 .h
#### 2.3 程序可容纳头文件数

一个程序理论上可以有无限个**不重名**的头文件
#### 2.4 分类

头文件被分为**库文件**与**自定义头文件**
库文件是已经 C 语言自己编写好的头文件；自定义头文件是用户自定义的头文件
#### 2.5 包含保护

不同的源文件可能会包含相同的头文件，会产生**重复包含**同个头文件的可能，所以需要在头文件内进行**包含保护**


>做法：
  定义专属于该头文件的宏（一般为头文件名全大写，`.`用下划线`_`代替）
  原理：
>源文件包含头文件时，会在头文件内进行**无参宏定义**，并编译头文件中包含的代码；当头文件已经被编译后，无参宏已经被定义，就不会再编译头文件中包含的代码

在头文件中使用包含保护的语法为
```c
#ifndef 头文件宏
#define 头文件宏

#endif
```

---
### 三、文件包含

#### 3.1 概念

文件包含是指将**相似功能**的代码放在一个源文件，包含**同名头文件**来使用代码（函数、变量等）
#### 3.2 包含文件

包含文件为**头文件**，通过包含头文件，可以使用**同名源文件**内的代码
使用包含文件的文件可以为源文件与头文件

>推荐：
>在头文件中只写源文件的相关声，文件包含放在源文件中
#### 3.3 语法

文件包含使用预处理指令`#include`

包含库文件的语法为
```c
#include <库文件>
```

包含自定义头文件的语法为
```c
#include "自定义头文件"
```

---
### 四、可执行文件

#### 4.1 概念

源文件与头文件都只是存放代码的文件，不能执行
通过编译，生成可执行文件（程序），才能执行
#### 4.2 拓展名

可执行文件的拓展名为 .exe
