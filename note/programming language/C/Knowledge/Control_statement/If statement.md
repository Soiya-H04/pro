#C #If #control_statement
## If 语句
---
### 一、概念
#### 1.1 判断条件

条件真值为真执行语句
#### 1.2 单分支

使用单分支 If 语句的语法为
```c
if(条件)
{
	语句;
}
```
#### 1.3 多分支

多分支`if`语句有**执行顺序**，只能执行一个`if`

使用多分支 If 语句的语法为
```c
if(条件1)
{
	语句1
}
else if(条件2)
{
	语句2
}
else if(条件3)
{
	语句3
}
···
```
#### 1.4 `else`

`else`接收条件都不匹配的情况

使用 else 语句的语法为
```c
if(条件1)
{
	语句1
}
else if(条件2)
{
	语句2
}
else
{
	语句3
}
```
