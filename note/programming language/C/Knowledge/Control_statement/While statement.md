## While 语句
---
### 一、概念

#### 1.1 循环条件

条件真值为真时执行一次循环，可为表达式，在执行完后判断结果是否满足循环条件
#### 1.2 分类

有两种循环方式：`do while`、`while`
#### 1.3 要求

每一次循环要更改循环条件

### 二、使用
#### 2.1 `while`

先判断在循环

使用`while`的语法为
```c
while(循环条件)
{
	语句;
}
```
#### 2.2 `do while`

执行一次再判断

使用 do while 的语句为
```c
do
{
	语句
}while(表达式)
```
