### 一、概念
#### 1.1 用途

提供用于进行标准输入输出操作的函数
#### 1.2 占位符

| 占位符         | 描述                                 |
| :---------- | :--------------------------------- |
| `%d`        | 十进制整数（有符号）                         |
| `%u`        | 无符号十进制整数                           |
| `%x` 或 `%X` | 十六进制整数（`%x`小写，`%X`大写）              |
| `%o`        | 八进制整数                              |
| `%f`        | 十进制浮点数（默认显示6位小数）                   |
| `%e` 或 `%E` | 科学计数法表示的浮点数（`%e`小写，`%E`大写）         |
| `%g` 或 `%G` | 根据数值大小自动选择`%f`或`%e`（`%g`小写，`%G`大写） |
| `%c`        | 单个字符                               |
| `%s`        | 字符串                                |
| `%p`        | 指针地址                               |
| `%n`        | 将到目前为止已打印的字符数存储到指定的变量中             |
#### 1.3 占位修饰

| 修饰符                      | 描述                                                                                |
| :----------------------- | :-------------------------------------------------------------------------------- |
| `width`（**宽度修饰符** ）      | 指定输出的**最小宽度**<br>如果实际内容宽度**小于**指定宽度，则用**空格**填充<br>如果实际内容宽度**大于**指定宽度，则按**实际宽度**输出 |
| `.precision`（**精度修饰符** ） | 对于浮点数，指定**小数点后的位数**<br>对于字符串，指定**最大字符数**                                          |
| `+`（**符号修饰符**）           | 强制在数值前显示正号或负号（正数前加`+`，负数前加`-`）<br>默认情况下，正数前**不显示**符号                              |
| ` `（**空格修饰符**）           | 在正数前加一个空格，负数前加一个`-`                                                               |
| `-`（**左对齐修饰符**）          | 左对齐**输出内容**，右侧**填充空格**<br>默认情况下是右对齐                                               |
| `0`（**填充字符修饰符**）         | 在**宽度不足**时，用`0`填充而不是空格<br>通常用于数字，使数字的输出宽度固定                                       |
#### 1.4 `FILE`

`FILE`为文件类型
#### 1.5 `size_t`

`size_t`为无符号整型，即为`unsigned int`

### 二、 基本输入输出函数

#### 2.1 `printf()`

将占位内容打印到终端

函数接口
```c
int printf(const char *format, ...);
```

>参数：
>`format`：格式控制字符串，指定输出数据的格式
>`...`：可变参数，要输出的数据

>返回值：
>返回输出字符数
#### 2.2 `scanf()`

将终端内容输入到占位内容，传给**地址**

函数接口
```c
int scanf(const char *format, ...);
```

>参数：
  `format`：格式控制字符串，指定输入数据的格式
>`...`：可变参数，用于存储输入数据的变量地址

>返回值：
>返回输入字符数
#### 2.3 `getchar()`

从标准输入设备（键盘）读取一个字符

函数接口
```c
int getchar(void);
```

>参数：
>无

>返回值：
>成功时返回读取字符的 ASCII 码，遇到文件结束符（EOF）时返回`EOF`
#### 2.4 `putchar()`

将一个字符输出到标准输出设备（屏幕）

函数接口
```c
int putchar(int ch);
```

>参数：
>`ch`：是要输出的字符或 ASCII 码

>返回值：
>成功时返回输出字符的 ASCII 码，失败时返回`EOF`

### 三、文件操作函数
#### 3.1 `fopen()`

打开一个文件

函数接口
```c
FILE *fopen(const char *filename, const char *mode);
```

>参数：
>`filename`：要打开的文件名
  `mode`：打开文件的模式
  
| 模式     | 描述                         |
| ------ | -------------------------- |
| `"r"`  | 只读模式，文件必须存在                |
| `"w"`  | 写入模式，如果文件存在则**覆盖**，不存在则创建  |
| `"a"`  | 追加模式，如果文件存在则在文件末尾追加，不存在则创建 |
| `"r+"` | 读写模式，文件必须存在                |
| `"w+"` | 读写模式，如果文件存在则覆盖，不存在则创建      |
| `"a+"` | 读写模式，如果文件存在则在文件末尾追加，不存在则创建 |
>返回值：
>成功时返回指向文件的指针，失败时返回`NULL`
#### 3.2 `fclose()`

关闭一个已打开的文件

函数接口
```c
int fclose(FILE *stream);
```

>参数：
>`stream`：要关闭的文件指针

>返回值：
>成功时返回`0`，失败时返回`EOF`
#### 3.3 `fprintf()`

将格式化的数据输出到指定的文件流

函数接口
```c
int fprintf(FILE *stream, const char *format, ...);
```

>参数：
>`stream`：输出流，指向文件的指针
>`format`：格式控制字符串
>`...`：可变参数，要输出的数据

>返回值：
>成功时返回输出的字符数，失败时返回负值
#### 3.4 `fscanf()`

从指定的文件流中读取数据，并根据指定的格式存储到变量中

函数接口
```c
int fscanf(FILE *stream, const char *format, ...);
```

>参数：
>`stream`：输入流，指向文件的指针
>`format`：格式控制字符串
>`...`：可变参数，用于存储输入数据的变量地址

>返回值：
>成功时返回成功读取的输入项数，失败时返回`EOF`
#### 3.5 `fread()`

从指定的文件流中读取数据块

函数接口
```c
size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
```

>参数：
>`ptr`：指向存储读取数据的缓冲区的指针
>`size`：每个数据块的大小（以字节为单位）
>`count`：要读取的数据块的数量
>`stream`：输入流，指向文件的指针

>返回值：
>成功时返回实际读取的数据块的数量
#### 3.6 `fwrite()`

将数据块写入指定的文件流

函数接口
```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);
```

>参数：
>`ptr`：指向要写入的数据的缓冲区的指针
>`size`：每个数据块的大小（以字节为单位）
>`count`：要写入的数据块的数量
>`stream`：输出流，指向文件的指针

>返回值：
>成功时返回实际写入的数据块的数量
#### 3.7 `fseek()`

在文件中移动读写指针的位置

函数接口
```c
int fseek(FILE *stream, long offset, int whence);
```

>参数：
>`stream`：文件流指针
>`offset`：偏移量（以字节为单位）
>`whence`：偏移的基准位置

| 基准位置       | 描述   |
| ---------- | ---- |
| `SEEK_SET` | 文件开头 |
| `SEEK_CUR` | 当前位置 |
| `SEEK_END` | 文件末尾 |
>返回值：
>成功时返回`0`，失败时返回非零值
#### 3.8 `ftell()`

获取文件指针的当前位置

函数接口
```c
long ftell(FILE *stream);
```

>参数：
>`stream`：文件流指针

>返回值：
>成功时返回文件指针的当前位置，失败时返回`-1L`
#### 3.9 `rewind()`

将文件指针重置到文件开头

函数接口
```c
void rewind(FILE *stream);
```

>参数：
>`stream`：文件流指针

>返回值：
>无
#### 3.10 `feof()`

检测文件指针是否已到达文件末尾

函数接口
```c
int feof(FILE *stream);
```

>参数：
>`stream`：文件流指针

>返回值：
>如果文件指针已到达文件末尾，返回非零值；否则返回`0`
#### 3.11 `fflush()`

刷新文件流的缓冲区，将缓冲区中的数据写入文件

函数接口
```c
int fflush(FILE *stream);
```

>参数：
>`stream`：文件流指针

>返回值：
>成功时返回`0`，失败时返回非零值
#### 3.11 `ferror()`

检测文件操作是否发生错误

函数接口
```c
int ferror(FILE *stream);
```

>参数：
>`stream`：文件流指针

>返回值：
>如果发生错误，返回非零值；否则返回`0`
