
---
### 一、概念
#### 1.1 用途

提供了动态内存分配、随机数生成、程序控制、数值转换等功能的函数

---
### 二、动态分配函数
#### 2.1 `malloc()`

分配指定字节的内存空间
分配的内存未初始化，内容是随机的

函数接口
```c
void* malloc(size_t size);
```

>参数：
>`size_t size`：需要分配的内存大小，以字节为单位

>返回值：
>成功时，返回一个指向分配的内存块的指针，类型为`void*`，失败时，返回`NULL`
#### 2.2 `calloc()`

分配指定数量的内存块，每个内存块的大小为指定大小，并将分配的内存初始化为`0`

函数接口
```c
void* calloc(size_t num, size_t size);
```

>参数：
>`size_t num`：要分配的内存块数量
>`size_t size`：每个内存块的大小，以字节为单位

>返回值：
>成功时，返回一个指向分配的内存块的指针，类型为`void*`。失败时，返回`NULL`
#### 2.3 `realloc()`

重新分配内存空间，可以扩大或缩小已分配的内存块大小

函数接口
```c
void* realloc(void* ptr, size_t size);
```

>参数：
>`void* ptr`：指向之前分配的内存块的指针，如果为`NULL`，则相当于调用`malloc`
>`size_t size`：新的内存大小，以字节为单位
#### 2.4 `free()`

释放之前分配的内存空间

函数接口
```c
void free(void* ptr);
```

>参数：
>`void* ptr`：指向之前分配的内存块的指针，如果为`NULL`，则不执行任何操作

>返回值：
>无返回值


### 三、程序控制函数
#### 3.1 `exit()`

终止程序运行，并返回指定的退出状态码

函数接口
```c
void exit(int status);
```

>参数：
>`int status`：程序的退出状态码，通常`0`表示成功，非`0`表示失败

>返回值：
>无返回值
#### 3.2 `system()`

执行指定的系统命令

函数接口
```c
int system(const char* command);
```

>参数:
>`const char* command`：要执行的系统命令字符串

>返回值：
>返回值取决于系统命令的执行结
>通常，返回值为0表示命令成功执行，非0表示命令执行失败

---
### 四、随机数函数
#### 4.1 `srand()`

设置随机数种子
种子决定了随机数生成器的**起始点**，不同的子会生成**不同**随机数序列
随机数生成器的**初始状态相同**，每次调用 `rand` 时返回的随机数序列**相同**

函数接口
```c
void srand(unsigned int seed);
```

>参数：
>`unsigned int seed`：随机数种子

>返回值：
>无
#### 4.2 `rand()`

生成一个伪随机数

函数接口
```c
int rand(void);
```

>参数：
>无

>返回值：
>一个由随机数生成器
