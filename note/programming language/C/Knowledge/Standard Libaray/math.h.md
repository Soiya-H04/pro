### 二、三角函数
#### 2.1 `sin()`

计算参数 `x` 的正弦值，其中 `x` 以弧度为单位

函数接口
```c
double sin(double x);
```

>参数：
>`double x`：以弧度为单位的角度

>返回值：
>返回 `x` 的正弦值，范围在 `-1` 到 `1` 之间
#### 2.2 `cos()`

计算参数 `x` 的余弦值，其中 `x` 以弧度为单位

函数接口
```c
double cos(double x);
```

>参数：
>`double x`：以弧度为单位的角度

>返回值：
>返回 `x` 的余弦值，范围在 `-1` 到 `1` 之间
#### 2.3 `tan()`

计算参数 `x` 的正切值，其中 `x` 以弧度为单位

函数接口
```c
double tan(double x);
```

>参数：
>`double x`：以弧度为单位的角度

>返回值：
>返回 `x` 的正切值
#### 2.4 `asin()`

计算参数 `x` 的反正弦值，返回值以弧度为单位

函数接口
```c
double asin(double x);
```

>参数：
>`double x`：范围在 `-1` 到 `1` 之间的值

>返回值：
>返回 `x` 的反正弦值，范围在 `-π/2` 到 `π/2` 之间
#### 2.5 `acos()`

计算参数 `x` 的反余弦值，返回值以弧度为单位

函数接口
```c
double acos(double x);
```

>参数：
>`double x`：范围在 `-1` 到 `1` 之间的值

>返回值：
>返回 `x` 的反余弦值，范围在 `0` 到 `π` 之间
#### 2.6 `atan()`

计算参数 `x` 的反正切值，返回值以弧度为单位

函数接口
```c
double atan(double x);
```

>参数：
>`double x`：任意实数值

>返回值：
>返回 `x` 的反正切值，范围在 `-π/2` 到 `π/2` 之间

### 三、指数、对数、幂、平方根函数
#### 3.1 `exp()`

计算 `e` 的 `x` 次幂，其中 `e` 是自然对数的底数

函数接口
```c
double exp(double x);
```

>参数：
>`double x`：指数

>返回值：
>返回 `e` 的 `x` 次幂
#### 3.2 `log()`

计算参数 `x` 的自然对数

函数接口
```c
double log(double x);
```

>参数：
>`double x`：大于0的值

>返回值：
>返回 `x` 的自然对数
#### 3.3 `log10()`

计算参数 `x` 的以10为底的对数

函数接口
```c
double log10(double x);
```

>参数：
>`double x`：大于0的值

>返回值：
>返回 `x` 的以10为底的对数
#### 3.4 `pow()`

计算 `x` 的 `y` 次幂

函数接口
```c
double pow(double x, double y);
```

>参数：
>`double x`：底数
>`double y`：指数

>返回值：
>返回 `x` 的 `y` 次幂
#### 3.5 `sqrt()`

计算参数 `x` 的平方根

函数接口
```c
double sqrt(double x);
```

>参数：
>`double x`：非负数

>返回值：
>返回 `x` 的平方根
### 四、绝对值与取整函数
#### 4.1 `fabs()`

计算参数 `x` 的绝对值

函数接口
```c
double fabs(double x);
```

>参数：
>`double x`：任意实数值

>返回值：
>返回 `x` 的绝对值
#### 4.2 `ceil()`

向上取整，返回不小于 `x` 的最小整数

函数接口
```c
double ceil(double x);
```

>参数：
>`double x`：任意实数值

>返回值：
>返回不小于 `x` 的最小整数
#### 4.3 `floor()`

向下取整，返回不大于 `x` 的最大整数

函数接口
```c
double floor(double x);
```

>参数：
>`double x`：任意实数值

>返回值：
>返回不大于 `x` 的最大整数
#### 4.4 `round()`

四舍五入，返回最接近 `x` 的整数

函数接口
```c
double round(double x);
```

>参数：
>`double x`：任意实数值

>返回值：
>返回最接近 `x` 的整数
