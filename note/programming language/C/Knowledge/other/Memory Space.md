#内存空间
## 内存空间
---
### 一、概念

#### 1.1 定义

内存空间存储计算机内所有需要**即时使用**的数据
#### 1.2 存储单位

内存空间中，最小的存储单位为**比特（bit）**，用于存储一个[[Storage code#1.2 进制|二进制]]（ 0 或 1）
多个 **bit** 连接可以存储更大的存储空间
更大的存储单位为 Byte（字节）、KB、MB、GB、TB、PB、EB、ZB、YB
存储单位换算为：
1 Byte = 8 bit
1 KB = $2^{10}$ Byte = 1024 Byte
1 MB = $2^{10}$ KB = 1024 KB
1 GB = $2^{10}$ MB = 1024 MB
1 TB = $2^{10}$ GB = 1024 GB
1 PB = $2^{10}$ TB = 1024 TB
1 EB = $2^{10}$ PB = 1024 PB
1 ZB = $2^{10}$ EB = 1024 EB
1 YB = $2^{10}$ ZB = 1024 ZB
#### 1.3 内存单元

内存空间不是一块完整的区域，而是分为一块块**内存单元**
每块内存单元所占空间的大小为 **1 Byte**，可以存储**两个十六进制**
#### 1.4 内存地址

每块内存单元都有特定的**内存地址**，以**十六进制**表示
内存地址指向内存单元，由**地址总线**管理
地址总线有 0、1 两种状态，表示**一个二进制**
32 位系统有 32 根地址总线，理论上可以管理 $2^{32}$ 个内存地址，即 4 GB 的内存空间
64 位系统有 64 根地址总线，理论上可以管理 $2^{64}$ 个内存地址，即 16 YB 的内存空间
但是由于实际技术、经济和实用性的限制，一般的 32 位系统的内存空间为 4 GB，64 位系统的内存空间为 32 GB
### 二、存储概念
#### 2.1 字节序

字节序（Endianess）是指在计算机存储多字的数据时，在内存空间中的**排列顺序**
字节序分**大端字节序**与**小端字节序**
大端字节序将**数据高位**存储在**低内存地址**，**数据低位**存储在**高内存地址**
小端字节序将**数据低位**存储在**低内存地址**，**数据高位**存储在**高内存地址**
#### 2.2 字节对齐

字节对齐是计算机存储不同数据类型的数据进行规则
字节对齐依靠**对齐数**，指定数据类型在内存空间内**首位内存单元**的**内存地址**
数据类型都有自己的对齐数

|   数据类型   | 对齐数 |
| :------: | :-: |
|  `char`  |  1  |
| `short`  |  2  |
|  `int`   |  4  |
|  `long`  |  4  |
| `float`  |  4  |
| `double` |  8  |
字节对齐默认情况下是按照**数据类型自身对齐数**进行对齐
使用预编译指令`#pragma pack`可以指定对齐数
使用指令后，所有数据都会以指定的对齐数进行存储

指定对齐数为`n`的语法为
```c
#pragma pack(n)
```
