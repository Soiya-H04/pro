#码制 #进制转换
## 存储码
---
### 一、概念

#### 1.1 定义

存储码是计算机**存储数据**的方式
#### 1.2 进制

| 进制   | 描述    |    取值     | 标识      |
| ---- | ----- | :-------: | ------- |
| 二进制  | 逢二进一  |   `0~1`   | 无       |
| 八进制  | 逢八进一  |   `0~7`   | 以 0 开头  |
| 十进制  | 逢十进一  |   `0~9`   | 无       |
| 十六进制 | 逢十六进一 | `0~9~A~F` | 以 0x 开头 |
#### 1.3 符号位

符号位表示**数据正负**
符号位为一个二进制（0 正 1 负）
**无符号型**存储不能为负的数据，符号位变为**存储数据位**
#### 1.4 原码

有符号整数，原码是**整数绝对值**二进制加一个**符号位**
符号位在原码的**第一位**，后接二进制
无符号整数，原码是整数二进制
#### 1.5 反码

正数的反码为其原码本身
负数的反码是原码的符号不变，二进制按位取反（0 取 1，1 取 0）
#### 1.6 补码

补码为计算机**存储整数**的方式
正数的补码为原码本身
负数的补码为反码加 1（符号位不变）
#### 1.7 浮点码

浮点码为计算机**存储浮点数**的方式
浮点码分为**阶码（J）**与**尾数(S)**，尾数与阶码都为**二进制**
浮点数 R 表示为
$$R=S*2^j$$

浮点码顺序为**符号位-阶码-尾数**
浮点数由于**精度（小数有效位数）**，阶码位数与尾数位数不同

|   浮点型    | 总位数 | 符号位 | 阶码位数 | 尾数位数 |
| :------: | :-: | :-: | :--: | :--: |
| `float`  | 32  |  1  |  8   |  23  |
| `double` | 64  |  1  |  11  |  52  |
>转换步骤：
>1. 将浮点数换算为二进制（整数部分除 2 求反余，小数部分乘 2 求整）
>2. 将二进制移动为规范的 1.xxxxxxx ，记录移动位数（小数点移动位数，左正右负）
>3. xxxxxxx 为尾数部分，如果位数不够，后补 0（1 为隐形存储，会在计算时隐性使用）
>4. 移动位数+偏移量转为二进制数为阶码部分（`float`型偏移量为 127，`double`型偏移量为1023）
