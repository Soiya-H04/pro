#C #关键字 
## 关键字
---
### 一、概念
#### 1.1 定义

关键字又称保留字，是 C 语言预先规定的具有**固定功能**的英语单词或单词缩写

### C 语言定义关键字

| 关键字        | 用途描述                                          |
| ---------- | --------------------------------------------- |
| `auto`     | 声明自动变量（默认存储类别，通常用于局部变量）。                      |
| `break`    | 用于跳出循环（如`for`、`while`、`do-while`）或`switch`语句。 |
| `case`     | 用于`switch`语句中的分支。                             |
| `char`     | 声明字符类型变量。                                     |
| `const`    | 声明常量，表示变量的值不能被修改。                             |
| `continue` | 用于跳过当前循环的剩余部分，继续下一次迭代。                        |
| `default`  | 用于`switch`语句中的默认分支。                           |
| `do`       | 用于`do-while`循环的开始。                            |
| `double`   | 声明双精度浮点数类型变量。                                 |
| `else`     | 用于`if-else`语句中的“否则”分支。                        |
| `enum`     | 声明枚举类型。                                       |
| `extern`   | 声明外部变量或函数，表示该变量或函数在其他地方定义。                    |
| `float`    | 声明单精度浮点数类型变量。                                 |
| `for`      | 用于`for`循环的开始。                                 |
| `goto`     | 无条件跳转到指定的标签。                                  |
| `if`       | 用于条件判断。                                       |
| `int`      | 声明整数类型变量。                                     |
| `long`     | 声明长整数类型变量。                                    |
| `register` | 声明寄存器变量，建议编译器将变量存储在寄存器中以提高访问速度。               |
| `return`   | 从函数返回，可以返回一个值（对于非`void`函数）或不返回值（对于`void`函数）。  |
| `short`    | 声明短整数类型变量。                                    |
| `signed`   | 声明有符号类型变量。                                    |
| `sizeof`   | 用于获取变量或类型的大小（以字节为单位）。                         |
| `static`   | 声明静态变量或函数，表示变量或函数具有静态存储期。                     |
| `struct`   | 声明结构体类型。                                      |
| `switch`   | 用于多分支选择结构。                                    |
| `typedef`  | 用于定义新的类型名称。                                   |
| `union`    | 声明联合体类型。                                      |
| `unsigned` | 声明无符号类型变量。                                    |
| `void`     | 声明无类型，用于表示函数没有返回值或参数。                         |
| `volatile` | 声明易失性变量，表示变量的值可能会被外部因素改变。                     |
| `while`    | 用于`while`循环的开始。                               |
