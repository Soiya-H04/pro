串口通信（Serial Communication）
包含头文件：REGX52.H。
寄存器：SCON、PCON、SBUF、SADDR、SADEN、IE、IP、IPH。


定时器：T1（需要禁止 T1 的中断，即 ET1 置 0。）。

接发数据：
1. 数据寄存器（SBUF）：
SBUF（用于发送接收。放在左边为发送；放在右边接收。）。
2. 接发规范：
为保证一个数据只发送一次，需要在赋值后使用确保该数据发送 while(TI == 0)，再将 TI 置零；使用中断接受数据，若 RI 为 1 则需要置零，并接受 SBUF。

串口控制：
1. 串口运行（IE、SCON）：
EA（中断总控。置 1 允许中断；置 0 禁止中断。）；
ES（串口中断控制。置 1 允许串口中断；置 0 禁止串口中断。）；
REN（接收使能，软件置位。置 1 允许接收；置 0 禁止接收。）。
2. 模式选择（SCON）：
SM0/FE		SM1
0			0：		移位寄存器；
0			1：		八位UART，波特率可变；
1			0：		九位UART（第九位为 TB8/RB8）；
1			1：		九位UART，波特率可变 （第九位为 TB8/RB8）。
3. 中断标志（SCON）：
当接收/发送到停止位（八位或九位）后，RI/TI 由硬件置 1，由软件置 0。
4. 中断优先级（IPH、IP）：
PSH	PS
0		0：	最低级；
0		1：	较低级；
1		0：	较高级；
1		1：	最高级。
5. 波特率选择（PCON）：
SMOD（复位置 0。置 1 时，模式 1、2、3 波特率加倍；置 0 时，模式波特率不加倍。）。
6. 帧错误检测（PCON）：
SMOD0（复位置 0。置 1 时，SM0/FE 作为 FE，用于检测帧错误；置 0 时，SM0/FE 作为 SM0，用于模式选择。）。
PS：
1. 波特率计算：
T1 溢出率=1/溢出周期（11 个时钟溢出一次，溢出周期就为 11。）。
波特率加倍：
T1 溢出率/16。
波特率不加倍：
T1 溢出率/32。
2. 波特率概念：
波特率（Baud Rate）表示单位时间内传送的码元符号的个数，即指一个单位时间内传输符号的个数，仅关注信号状态变化次数（如电平跳变）。
