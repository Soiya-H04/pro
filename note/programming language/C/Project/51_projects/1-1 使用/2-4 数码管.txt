数码管（Digital Tube）
包含头文件：REGX52.H。
寄存器：P0、P2。


亮灭逻辑：一个 bit 位代表一根数码管亮灭（置 0 时，数码管灭；置 1 时，数码管亮。）。

位置逻辑（P0、P2）：
1. 位寻址：
数码显示位（P2）：
3 个bit 位表示 8 个数码显示位，按 LED8->LED1 排列。
		P2_4	P2_3	P2_2
LED1：	0 		0 		0	

···	|		|		|

LED8：	1		1		1
2. 寄存器寻址：
数码管（P0）：
按照 a b c d e f g dp 顺时针排列，每根数码管一个 bit 位。
	      
	  __a __
	|	      |
	f	      b
	|__ g__|
	|	      |
	e	      c
	|__d __|	dp·

dp	g	f	e	d	c	b	a
0	0	0	0	0	0	0	0

数字：			1			2			3			4			5			6			7			8			9			0
二进制		：	00000110	01011011	01001111	01100110	01101101	01111101	00000111	01111111	01101111	00111111
十六进制	：	0x06		0x5B		0x4F		0x66		0x6D		0x7D		0x07		0x7F		0x6F		0x3F

PS：
数码显示：
1. 问题：
一般显示数字是先选位置再选数，但是有时候会选位置后还没有选数时，会显示上一个位置的数。
2. 解决：
在选位置时，先将数清空
