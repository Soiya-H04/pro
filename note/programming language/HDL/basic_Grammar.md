## 一、语句块

---

---

Verilog 中的语句块主要分为顺序块和并行块。  

语句块不能单独使用，需要依赖

-   **过程块**（`always`、`initial`）
-   **条件语句**（`if`、`else`、`case`）
-   **循环语句**（`for`、`while`、`repeat`）
-   **任务（task）或函数（function）**
-   **生成块（`generate`）**

---

### 1-1 顺序块



顺序块内的语句按顺序依次执行，前一条语句执行完毕后才会执行下一条。  



#### 声明格式

顺序块的声明格式

```verilog
begin : <块名>
   <执行语句>;
end
/*
块名（可选）：在需要时可以给块命名，便于调试或通过 disable 终止。  
执行语句：需要顺序执行的语句。  
*/
```



实例：

```verilog
begin  : my_block  	// 命名顺序块
	a = 1'b1; 	    // 先执行
    b = 2'b11;  	// 后执行
    c = 1'b1; 	    // 最后执行
end

begin : my_block
a <= 1'b1;
    b <= 2'b11;
    c <= 1'b1;
end
```



**注意：**

-   **在顺序块里对一个信号进行多次赋值，取最后一次的值**

-   **禁止在同一个块中混合使用两种赋值**

---

### 1-2 并行块



并行块中的所有语句会在同一仿真时间起点同时执行，即在语句块开始时同时执行。  



#### 声明格式

并行块有两种声明格式，分别有不同的逻辑

```verilog
// 当所有语句执行完后继续
fork : <块名>
    <执行语句>;
join
/*
块名（可选）：在需要时可以给块命名,通过 disable 语句终止命名块的执行。  
执行语句：需要并行执行的语句。  
*/

// 当任意一条语句执行完后继续
fork : <块名>
    <执行语句>;
join_any
/*
块名（可选）：在需要时可以给块命名,通过 disable 语句终止命名块的执行。  
执行语句：需要并行执行的语句。  
*/
```



实例：

```verilog
fork : my_block
	a = 1'b1;
    b = 2'b11;  // 一起执行，所有语句结束就继续
    c = 1'b1;
join

fork : my_block
	a <= 1'b1;
    b <= 2'b11;  // 一起执行，一个语句结束就继续
    c <= 1'b1;
join_any
```

## 二、always 语句

---

---

always 语句用于描述重复执行或由特定事件触发的逻辑。  

always 语句需要定义在  module 中。

---

### 2-0 基本格式



always 语句的基本格式为

```verilog
always @(<敏感列表>)
    <语句块>

/*
敏感列表：当满足敏感列表里的条件时，执行 always 语句里的语句块。  
语句块：即顺序块与并行块
*/
```

---

### 2-1 敏感列表



敏感列表用于指定一组信号，当这些信号发生特定变化时，always 语句里的语句块会被执行。  



#### a. 类型

敏感列表根据触发方式分为两类

| 触发方式   |           边沿触发           |             电平触发             |
| ---------- | :--------------------------: | :------------------------------: |
| 触发条件   |      信号电平边沿的变化      |        信号保持在特定电平        |
| 效果       | 瞬时触发，仅在信号边沿发生时 | 持续触发，只要信号保持在触发电平 |
| 常见用途   |           时序逻辑           |             组合逻辑             |
| 抗干扰能力 |     较强，有效避免误触发     |   较弱，容易受到信号抖动的影响   |



#### b. 触发逻辑



##### 边沿触发

当信号（wire、reg）发生上升沿（`posedge`，从低电平变为高电平）或下降沿（`negedge`，从高电平变为低电平）时，always 块内的逻辑被执行。  

敏感列表里面是信号的上升沿或下降沿，用 `or` 隔开。

边沿触发用于描述时序逻辑（如寄存器、触发器、计数器等）。  

使用边沿触发的格式为

```verilog
always @(posedge <信号上升沿> or negedge <信号下降沿>) begin
    <执行语句>;
end
/*
信号上升沿：在低电平转换为高电平的瞬间触发。  
信号下降沿：在高电平转换为低电平的瞬间触发。  
执行语句：边沿触发需要执行的语句。  
*/
```



实例：

```verilog
always @(posedge up or negedge down) begin 
    a = 1;
end
```



##### 电平触发

敏感列表里面是信号，用 `or` 隔开。

当敏感列表里的信号（wire、reg）发生变化时，always 块内的逻辑被执行。  

用于描述组合逻辑（如多路选择器、加法器）。  

使用电平触发的格式为

```verilog
always @(<信号>) begin
    <执行语句>;
end
/*
信号：只要达到了特定电平就会触发，用 or 连接。  
执行语句：电平触发需要执行的语句。 
*/
```



实例：

```verilog
always @(a or c) begin
    b = 2;
end
```



**特殊情况：**

敏感列表里的信号有很多时，可以使用 `*`  来代替。

所以会提供一个语法糖，`*` 用于表示模块里的所有信号，格式为

```verilog
always @(*) begin
    <执行语句>;
end
/*
执行语句：需要执行的语句。 
*/
```



**限制：**

-   **敏感条件里的触发保持同种触发方式**

## 三、assign 语句

---

Verilog 中的 assign 语句是一种连续赋值语句，用于描述组合逻辑电路。  

assign 是独立语句，不能在 always 或 initial 块内部使用。  

assign 语句需要定义在  module 中。  

assign 语句只能驱动线网类型（wire）的信号。  

-----

#### 声明格式



assign 语句将表达式的逻辑赋给 wire 类型的信号，只要表达式里的信号改变，wire 类型的信号也会立即更新。  

assign 语句的基本格式为

```verilog
assign <信号> = <表达式>;
/*
信号：wire 类型，不能是 reg 类型。  
表达式：可以是任意合法的表达式，包括信号、运算符、常量或函数调用。  
*/
```



实例：

```verilog
wire a, b, c;
assign c = a & b;  // 实现与门

wire [7:0] data_in, data_out;
assign data_out = enable ? data_in : 8'b0; // 三态门控制

wire [3:0] sum;
assign sum = a + b + (carry_in << 1); // 加法器逻辑
```

## 五、module 语句

---

---

Verilog 中的 module 是定义模块的基本语法结构，用于封装逻辑功能。  

----

### 5-1 端口



在 Verilog 中，端口（Port）是模块（Module）与外部世界交互的接口，用于定义模块的输入、输出以及双向通信信号。  

在 Verilog 里有三种类型的端口

| 端口类型 |                 输入端口                 |                 输出端口                 |                     双向端口                     |
| -------- | :--------------------------------------: | :--------------------------------------: | :----------------------------------------------: |
| 符号     |                 `input`                  |                 `output`                 |                     `inout`                      |
| 特点     | 从模块外部接收信号<br>不能在模块内部赋值 | 从模块内部发送信号<br>不能从外部接收信号 | 既可以作为输入也可以作为输出<br>需要三态逻辑控制 |
| 支持类型 |                   wire                   |                wire、reg                 |                    wire、reg                     |



#### 声明格式



如果有多个端口用 `,` 隔开，最后一个端口后没有 `,`。  

端口的声明格式为

```verilog
<端口类型> <数据类型> <位宽> <端口名>
/*
端口类型：端口的类型。
数据类型（可选，默认为 wire）：端口的数据类型。
位宽（可选，默认为 1）：即有多少个比特位。
端口名：端口的名字。
*/
```

---

### 5-2 声明格式



module 的声明格式一般推荐为

```verilog
module <模块名> (<端口列表>);
    <端口声明>
    <内部信号/变量声明>
    <模块逻辑>
endmodule
/*
模块名：模块的名字
端口声明：input/output/inout 等端口的声明，用 ,  隔开。  
内部信号/变量声明：wire、reg 等信号的声明。  
模块逻辑：模块的具体逻辑。  
*/
```

h实例：

```verilog
module my_module (
    input wire [2:0] i,
    output reg [1:0] o,
    inout wire io
);
    wire in_val;
    assgin in_val = 1'b1;
    always @(*) begin
        o <= i;
        oi <= i;
    end

endmodule
```

## 六、if 语句

---

---

Verilog 中的 if 语句是一种条件分支控制结构，用于根据条件执行不同的代码块。  

if 语句用于 always 语句或 initial 语句。  

---

### 6-1 单分支



如果只有单种情况需要判断的话，使用单分支的 if 语句。  



#### 声明格式



单分支的 if 语句的声明格式为

```verilog
if (<条件>) 
    <语句块 1>
else
    <语句块 2>
/*
条件：一个表达式，可以为常数，信号或逻辑组合。
语句块 1：条件为真时执行的语句块。
语句块 2：条件为假时执行的语句块。
*/
```



实例：

```verilog
if (a) begin
   b = 1'b1;  // a 不为假（0）时执行
end
else begin
   b = 1'b0;  // a 为假（0）时执行
end
```

---

### 6-2 多分支



如果有多种情况需要判断的话，使用多分支的 if 语句。  



#### 声明格式



多分支的 if 语句的声明格式为

```verilog
if (<条件 1>) 
    <语句块 1>
else if (<条件 2>) 
    <语句块 2>
else
    <语句块3>
/*
条件 1：一个表达式，可以为常数，信号或逻辑组合。
语句块 1：条件 1 为真时执行的语句块。
条件 2：一个表达式，可以为常数，信号或逻辑组合。
语句块 2：条件 2 为真时执行的语句块。
语句块 3：条件 1 与条件 2 都为假时执行的语句块。
*/
```



**限制：**

-   **当上面的条件满足后就不会再进行下面的条件判断**



实例：

```verilog
if (a == 1'b1) begin  // 如果满足就不进行后面的条件判断
   b = a;
end
else if (a == 1'b0) begin
    b = ~a;
end
else begin
   b = 1'b0; 
end
```

## 七、case 语句

---

---

Verilog 中的 case 语句是一种多路分支控制结构。  

可以看为多分支的 if 语句，但其不会有条件的优先级，是一起进行判断。

case 语句根据输入表达式的不同取值，执行对应的代码分支。

case 语句用于 always 语句或 initial 语句。  

---

### 声明格式



case 语句的声明格式为

```verilog
case (<表达式>)
    <值 1>:
        <语句块 1>
    <值 2>:
        <语句块 2>
    <值 3>:
        <语句块 3>
    default:
        <语句块 4>
endcase
/*
表达式：可以为一个常量，信号与逻辑组合。
值 1：常量或常量表达式。
语句块 1：表达式的值与值 1 相等时执行的语句。
值 2：常量或常量表达式。
语句块 2：表达式的值与值 2 相等时执行的语句。
值 3：常量或常量表达式。
语句块 3：表达式的值与值 3 相等时执行的语句。
语句块 4：表达式的值与上面值都不匹配时执行的语句。
*/
```



实例：

```verilog
case (data)
    2'b00: out = a;  // 如果只有一行不需要用顺序块与并行块
    2'b01: out = b;
    2'b10: out = c;
    2'b11: out = d;
    default: out = 1'bx;
endcase
```

## 八、for 语句

---

---

Verilog 中的 for 循环语句是一种根据要求重复特定代码的控制语句。  

for 语句用于 always 语句或 initial 语句。  

----

### 声明格式



for 语句的声明格式为

```verilog
for (<初始化>; <条件>; <迭代>)
    <语句块>
/*
初始化：设置循环变量的初始值。
条件：循环继续的条件。
迭代：每次循环后对变量的操作。
语句块：需要循环执行的语句。
*/
```



**限制：**

-   **循环次数必须在编译/综合时确定，不能依赖运行时变量（如动态输入值）**
-   **循环体的所有迭代在硬件中是并行的，而非顺序执行，即每次迭代都互相关联**



实例：

```verilog
integer i;
for (i = 0; i < 8; i = i + 1) begin
    parity = parity ^ data[i]; // 所有异或操作并行执行
end
```

## 十、repeat 语句

---

---

Verilog中的 repeat 语句为重复执行一段代码指定的次数。  

repeat 语句用于 always 语句或 initial 语句。  

---

### 声明格式



repeat 语句的格式为

```verilog
repeat (<次数表达式>) 
    <语句块>
/*
次数表达式：决定循环次数的表达式，需要常量。
语句块：需要重复执行的代码。
*/
```



**注意：**

实例：

```verilog
repeat(8) begin

    i = i + 1;
end
```

## 十一、task 语句

---

---

在 Verilog 中，task 是一种用于封装可重复使用代码的结构，类似于其他编程语言中的函数，但具有独特的硬件描述语言特性。

task 语句需要在 module 里声明。

---

### 11-1 声明格式



task 语句的声明格式为

```verilog
task <task名>;
  input  <输入参数>;  // 输入声明
  output <输出参数>;  // 输出声明
  <语句块>
endtask
/*
task名：task 的名字。
输入参数：输入的参数，可以是常量、表达式或 wire/reg 变量。
输出参数：输出的参数，必须为 reg 类型
语句块：需要封装的语句。
*/
```



**注意：**

-   **直接通过 output 参数修改值，而非返回结果**
-   **输出参数需在调用前声明为 reg 类型**



实例：

```verilog
task calc_and;
  input  [7:0] a, b;
  output [7:0] result;
  begin
    result = a & b;  // 按位与操作
  end
endtask
```

---

### 11-2 调用方式



使用 task 的方式就是调用 task 的名字。

task 调用格式为

```verilog
<task名>(<输入参数>, <输出参数>);
/*
task名：定义的 task 名。
输入参数：定义的输入参数。
输出参数：定义的输出参数。
*/
```



**注意：**

-   **参数顺序必须与任务定义中 input、output、inout 的声明顺序一致**
-   **task 只能够在 initial、always、function、task 中调用**



实例：

```verilog
reg [7:0] x = 8'hAA, y = 8'h0F, z;
calc_and(x, y, z);  // z = 8'h0A
```

## 十二、function 语句

---

---

Verilog 中的 function 语句用于定义可重复使用的代码块，其目的是执行特定操作并返回一个单一值。

函数通常用于组合逻辑（无时序控制），且不能包含延迟（如 `#`）或事件控制（如 `@(posedge clk)`）

---

### 12-1 声明格式



声明时的返回值要赋值给函数名。

functon 语法的声明格式为

```verilog
function <返回类型> <function名>;
  input <输入参数>;
  <语句块>
endfunction
/*
function名：function 的名字，返回值要赋予的对象。
返回类型：返回值的类型，默认为 reg，可以是 integer、real 等。
输入参数：输入的参数，默认为 reg，可以是 integer、real 等。
语句块：需要封装的语句。
*/
```

​	

**注意：**

-   **必须有输入参数**
-   **通过函数名返回一个值**
-   **函数中不能包含 `#`、`@`等时序相关语句**



实例：

```verilog
function [4:0] add_4bit;
  input [3:0] a, b;
  begin
    add_4bit = a + b; // 返回值赋值给函数名
  end
endfunction
```

---

### 12-2 调用方式



使用 function 的方式就是调用 function 的名字。

function 的调用方式为

```verilog
<function名>(<输入参数>);
/*
function名：定义的 function 名。
输入参数：定义的输入参数。
*/
```



实例：

```verilog
wire [4:0] sum = add_4bit(4'b1010, 4'b0011); // sum = 5'b01101
```

## 十三、模块调用

---

---

每个模块代表一个独立的功能单元，都定义了输入输出端口和内部逻辑。

通常将被调用的模块称为子模块，调用的模块称为父模块。

模块之间的调用通过在父模块里实例化实现，可以对同个子模块多次实例化。

实例化需指定实例名称与连接方式（主要为按名称连接）。

---

### 调用格式



输入端口可连接至父模块的 reg 或 wire，输出端口必须连接至父模块的 wire。

模块的调用格式为

```verilog
<子模块名> <实例名> (.<子模块端口名>(<父模块信号>));
/*
子模块名：需要调用的模块。
实例名：被调用模块的实例名。
子模块端口名：被调用端口的端口。
父模块信号：调用模块的信号。
*/
```



**注意：**

-   **子模块端口与父模块的信号的类型与位宽要一致**
-   **同一父模块中实例名不可重复**



实例：
```verilog
module AND(input a, input b, output c);
    assign c = a & b;
endmodule

module Top;
    reg  a, b;
    wire c;
    AND and(.a(a), .b(b), .c(c));
endmodule
```
