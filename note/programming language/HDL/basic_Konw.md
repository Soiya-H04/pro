### 1-0 电路逻辑



在电路里的设计逻辑主要分为组合逻辑与时序逻辑

|      |                           组合逻辑                           |                           时序逻辑                           |
| ---- | :----------------------------------------------------------: | :----------------------------------------------------------: |
| 定义 |                     取决于当前信号的逻辑                     |              取决于当前输入信号与存储信号的逻辑              |
| 特点 | 输出与过往信号无关，只取决于当前输入<br>没有存储元件<br>输出信号会随输入信号改变立即改变<br>通常不需要时钟信号 | 与当前输入信号与过往信号有关<br>有存储元件（触发器、寄存器）<br>具有记忆功能<br>一般需要时钟信号 |

### 1-2 逻辑状态



在 Verilog 里总共有四种逻辑状态  

| 逻辑值 | 含义               | 常见用途                                                     |
| ------ | ------------------ | ------------------------------------------------------------ |
| **0**  | 布尔假，逻辑低电平 | 用于表示数字电路中的低电平信号                               |
| **1**  | 布尔真，逻辑高电平 | 用于表示数字电路中的高电平信号                               |
| **z**  | 高阻态，类似断路   | 常用于三态总线，允许多个设备共享同一信号线，但只有一个设备驱动信号 |
| **x**  | 未知态             | 通常在设计初期或未初始化的信号中出现，用于表示不确定的信号状态 |

### 1-3 数值



Verilog 的整数格式  

```verilog
<位宽>'<进制><数值>
/*
位宽（可选）：十进制数，表示有多少个比特位，不写计算机自己指定。
进制：数值所使用的进制
数值：所选进制内可以存储在位宽最大值的数（当数值位宽大于指定大小截去高位），也可以写不定值 x 与高阻态 z
*/
```

支持的整数的进制  

|    进制类型    | 符号 |
| :------------: | ---- |
|     二进制     | `b`  |
|     八进制     | `o`  |
| 十进制（默认） | `d`  |
|    十六进制    | `h`  |

### 1-4 标识符



在 Verilog 中，标识符用于命名模块、信号、端口、参数等。  

正确使用标识符是编写清晰、可读代码的基础。  

标识符可以包含字母（`A-Z` 和 `a-z`）、数字（`0-9`）和下划线（`_`）。  



**限制：**

-   **标识符不能以数字开头**
-   **区分大小写（如 `Module` 和 `module` 是不同的标识符）**



**推荐：**

-   **保持标识符简洁明了并保持一致性**
-   **使用有意义的名字与后缀**
-   **自定义缩写在文件头进行注释**
-   **使用大写字母表示常量，使用小写字母表示信号。**

### 1-7 时间延迟



用 `#` 符号定义时间的延迟。  

延迟的单位由 `'timescale` 来决定。

`'timescale`  的基本格式为   `'timescale 时间单位/时间精度`

延迟时间的基本格式

```verilog
#<延迟时间>
/*
时间延迟：一个整数，代表延迟整数个时间精度的时间。
*/
```



实例：

```verilog
'timescale 1ns/1ps  // 时间单位=1ns，时间精度=1ps
#5;  // 延迟 5ns
#5 a = 1;  // 延迟 5ns 进行赋值
```



**注意：**

-   **只能在过程性语句里使用**

### 2-1 wire



wire 信号表示物理连线，用于连接模块内部和模块之间的信号。  



#### 声明格式

wire 类型的声明格式为  

```verilog
wire <符号> <位宽> <信号名> = <初始值>;
/*
符号（可选，默认为 unsigned）：规定了数据范围，有符号的数据范围会包含符号。
位宽（可选，默认为1）：表示信号的宽度，可以是单比特（如 wire a;），也可以是多比特（如 wire [7:0] bus; 表示一个 8 位的总线），可以表示从 0~255 的整数值。
信号名：用户自定义的信号名称。
初始值（可选）：未设定时为 x，一般为二进制，其他进制也会转换为二进制进行存储。
*/
```



**限制：**

-   **位宽范围必须为合法整数**
-   **信号名唯一**
-   **必须在模块内声明与使用**
-   **不能在过程性块（`always` 块或 `initial` 块）里声明**



实例：

```verilog
/*
申明 wire 类型信号
*/
wire unsigned_data1 = 1'b1;		// 单位无符号 wire 信号，范围为 0~1，定义为 1'b1
wire [7:0] unsigned_data2;  	// 8位无符号 wire 信号，范围为 0~255
wire signed [7:0] signed_data;	// 8位有符号 wire 信号，范围为 -128~127
```



#### 赋值

wire 类型能接受逻辑状态与数值，在未被赋值前默认为 `x`。  

wire 类型使用 assign 语句进行赋值，赋值格式为

```verilog
assign 信号 = 表达式;
/*
信号：wire 类型，如果是多位宽，能够对其单位进行赋值。
表达式：任何可以赋值给 wire 类型的值。
*/
```



**限制**：

1.   **wire 类型的信号可以被多个其他信号引用，但不能被多次赋值**
2.   **不能在 `always` 块与 `initial` 块与 `for` 与 `while` 等过程性语句中赋值**
3.   **wire 类型的信号不能直接使用 `=` 进行赋值**



实例：

```verilog
// 赋值组合逻辑值
assign c = a & b; 		  // 将逻辑与赋值给 wire 信号
assign d = 12;  		  // 赋值数值

// 赋值给信号的指定位置
assign e[3:1] = 3'b101;	 // 将第4位到第2位（索引3到1）赋值为3'b101
assign f[1] = 1'b1;		 // 将第2位（索引1）赋值为1'b1
```

### 2-2 reg



reg 类型的信号可以存储数据。

因此 reg 类型常用于时序逻辑电路。



#### 声明格式

```verilog
reg <位宽> 信号名 <数组维度> = <初始值>;
/*
位宽（可选,默认为 1）：表示这个信号可以存储多少位的二进制数据。
信号名：用户指定的信号名称。
数组维度（可选）：表示这个 reg 信号是一个数组，指定了数组的大小。
初始值（可选）：未设定时为 x，一般为二进制，其他进制也会转换为二进制进行存储。
*/
```



实例：

```verilog
// 单个 reg 信号
reg [3:0] my_reg = 4'b0011;  				// 4位宽，初始值为二进制的0011

// 多个 reg 信号
reg [7:0] data1 = 8'd100, data2 = 8'd200;   // 8位宽，初始值分别为100和200
reg [3:0] reg1 = 4'b0001, reg2 = 4'b0010;   // 4位宽，初始值分别为0001和0010

// reg 数组
reg [7:0] my_array [0:15] = {8'd0, 8'd1, 8'd2, 8'd3, 8'd4, 8'd5, 8'd6, 8'd7, 8'd8, 8'd9, 8'd10, 8'd11, 8'd12, 8'd13, 8'd14, 8'd15};  // 16个元素的8位宽数组，初始化为0到15

// 多维reg数组
reg [3:0] my_2d_array [0:3][0:3] = {
    {4'b0000, 4'b0001, 4'b0010, 4'b0011},
    {4'b0100, 4'b0101, 4'b0110, 4'b0111},
    {4'b1000, 4'b1001, 4'b1010, 4'b1011},
    {4'b1100, 4'b1101, 4'b1110, 4'b1111}
};
```



#### 赋值

可以使用阻塞赋值与非阻塞赋值。



实例：

```verilog
// 阻塞赋值
temp = a + b;

// 非阻塞赋值
count <= 4'b0000; 
```

### 2-3 parameter



parameter 类型用于定义常量，类似于 C 语言中的宏定义。

Verilog 有两种 parameter 类型

| 类型       | 可覆盖性       | 作用域           |
| ---------- | -------------- | ---------------- |
| parameter  | 实例化时可修改 | 全局（模块内外） |
| localparam | 不可修改       | 模块内           |



#### 声明格式

parameter 类型可以赋值为常量或表达式（表达式为常量构成）。

一般声明放在模块开头，且声明时就进行赋值。

parameter 类型在声明后不可被修改。

parameter 类型的声明格式为

```verilog
parameter <参数名> = <初始化值>;
localparam <参数名> = <初始化值>;
/*
初始化值：默认为整数，但可显式指定类型（如 real、string 等）。
*/
```



实例：

```verilog
parameter N = 16;  // 设置参数 N 为 16
parameter M = N * 2;  // M = 32

localparam L = 17;  // 设置参数 N 为 17
localparam P = L / 2  // P = 8
```

### 2-4 time



在 Verilog 中，time 是一种特殊的数据类型，主要用于存储和操作时间。

time 类型是一个 64 位无符号整数，默认值为 `64'h0`（即全零）。



#### 声明格式

time 类型的声明格式为

```verilog
time <时间信号> = <初始化值>;
/*
时间信号：time 类型。
初始化值（可选）：为 time 类型的值。
*/
```

### 3-1 算术运算符



算术运算符返回计算结果

| **运算符** | **名称**     | **类型**   | **功能**                   | **注意事项**                                                 |
| :--------- | :----------- | :--------- | :------------------------- | :----------------------------------------------------------- |
| `+`        | 加法         | 双目       | 两个操作数相加             | 支持整数、向量（按位相加）。                                 |
| `-`        | 减法/取负    | 双目或单目 | 双目时为减法，单目时为取负 | 单目取负常用于常数或表达式（如 `-3'd2`）。                   |
| `*`        | 乘法         | 双目       | 两个操作数相乘             | 综合可能生成复杂组合逻辑（尤其是变量位宽时）。               |
| `/`        | 除法         | 双目       | 两个操作数相除             | 结果向下取整（如 `5/3=1`）；综合时需谨慎，通常要求除数为常数或2的幂。 |
| `%`        | 取模（求余） | 双目       | 返回除法的余数             | 余数符号与第一个操作数相同（如 `-7%3 = -1`）；综合时需确保操作数为常数。 |



**注意：**

-   **操作数位宽不同时，Verilog 会自动扩展较短操作数的高位补零，可能导致意外结果。建议手动对齐位宽。**

-   **乘/除/取模运算在 FPGA 综合时可能消耗大量逻辑资源，建议优化设计（如用移位代替乘除2的幂次）。**

### 3-2 关系运算符



关系运算符返回逻辑值

| **运算符** | **名称**   | **类型** | **功能**                     | 限制                   |
| :--------- | :--------- | :------- | :--------------------------- | ---------------------- |
| `>`        | 大于       | 双目     | 左操作数是否大于右操作数     | 当有  `x/z` 时返回 `x` |
| `<`        | 小于       | 双目     | 左操作数是否小于右操作数     | 同上                   |
| `>=`       | 大于等于   | 双目     | 左操作数是否大于等于右操作数 | 同上                   |
| `<=`       | 小于等于   | 双目     | 左操作数是否小于等于右操作数 | 同上                   |
| `==`       | 逻辑等于   | 双目     | 逻辑相等比较                 | 同上                   |
| `!=`       | 逻辑不等于 | 双目     | 逻辑不等比较                 | 同上                   |
| `===`      | 全等       | 双目     | 严格按位比较（含 `x/z`）     | 只会返回 `0` 或 `1`    |
| `!==`      | 非全等     | 双目     | 严格按位不等比较             | 同上                   |



**注意：**

-   **操作数位宽不同时，Verilog 会自动扩展较短操作数的高位补零，可能导致意外结果。建议手动对齐位宽。**

### 3-3 逻辑运算符



逻辑运算符返回逻辑值  

| **运算符** | **名称** | **类型** | **功能**               | **返回值规则**                                         |      |      |
| :--------- | :------- | :------- | :--------------------- | :----------------------------------------------------- | ---- | ---- |
| `&&`       | 逻辑与   | 双目     | 两操作数均为真时返回真 | 若两操作数均非零，返回 `1'b1`；否则返回 `1'b0`。       |      |      |

| `!`        | 逻辑非   | 单目     | 对操作数取反           | 若操作数为零，返回 `1'b1`；若操作数非零，返回 `1'b0`。 |      |      |

### 3-4 移位运算符



移位运算符返回移位结果  

| **运算符** | **名称** | **类型** | **功能**                                             | **操作规则**                                                 |
| :--------- | :------- | :------- | :--------------------------------------------------- | :----------------------------------------------------------- |
| `<<`       | 逻辑左移 | 双目     | 将左操作数向左移位，右侧补零。                       | 移位位数由右操作数指定。示例：`4'b1010 << 2` → `4'b1000`（高位溢出，低位补零）。 |
| `>>`       | 逻辑右移 | 双目     | 将左操作数向右移位，左侧补零。                       | 适用于无符号数。示例：`4'b1010 >> 1` → `4'b0101`。           |
| `<<<`      | 算术左移 | 双目     | 将左操作数向左移位，右侧补零（与逻辑左移行为相同）。 | 行为与 `<<` 一致。示例：`4'b1010 <<< 1` → `4'b0100`（符号位可能被移出，结果可能不直观）。 |
| `>>>`      | 算术右移 | 双目     | 将左操作数向右移位，左侧补第一位。                   | 保留符号位。示例：`4'b1010 >>> 1` → `4'b1101`（符号位 `1` 被保留并填充）。 |

### 3-5 位运算符



位运算符返回位运算结果  

| **运算符**   | **名称** | **类型** | **功能**                             | **操作规则**                                                 |
| :----------- | :------- | :------- | :----------------------------------- | :----------------------------------------------------------- |
| `&`          | 按位与   | 双目     | 对两个操作数的每一位进行逻辑与操作。 | 对应位均为 `1` 时结果为 `1`，否则为 `0`。 示例：`4'b1010 & 4'b1100 → 4'b1000`。 |
| `|`          | 按位或   | 双目     | 对两个操作数的每一位进行逻辑或操作。 | 对应位至少一个为 `1` 时结果为 `1`，否则为 `0`。 示例：`4'b1010 | 4'b1100 → 4'b1110`。 |
| `~`          | 按位非   | 单目     | 对操作数的每一位进行逻辑取反。       | 将 `0` 变为 `1`，`1` 变为 `0`。 示例：`~4'b1010 → 4'b0101`。 |
| `^`          | 按位异或 | 双目     | 对两个操作数的每一位进行异或操作。   | 对应位不同时结果为 `1`，否则为 `0`。 示例：`4'b1010 ^ 4'b1100 → 4'b0110`。 |
| `~^` 或 `^~` | 按位同或 | 双目     | 对两个操作数的每一位进行同或操作。   | 对应位相同时结果为 `1`，否则为 `0`。 示例：`4'b1010 ~^ 4'b1100 → 4'b1001`。 |



**注意：**

-   **若两个操作数位宽不同，较短操作数的高位补零，直到与较长操作数位宽一致**

### 3-6 条件运算符



条件运算符返回条件运算结果  

| **运算符** | **语法**               | **类型** | **功能**                           | **返回值规则**                                               |
| :--------- | :--------------------- | :------- | :--------------------------------- | :----------------------------------------------------------- |
| `?:`       | `cond ? expr1 : expr2` | 三目     | 根据条件 `cond` 的真假选择返回值。 | 若 `cond` 为真（非零），返回 `expr1`；若 `cond` 为假（零），返回 `expr2`。 |

### 3-7 拼接运算符



拼接运算符返回拼接结果  

| **运算符** | **语法**              | **功能**                            | **规则与示例**                                               |
| :--------- | :-------------------- | :---------------------------------- | :----------------------------------------------------------- |
| `{}`       | `{expr1, expr2, ...}` | 将多个表达式按顺序拼接为单一向量。  | 拼接顺序为从左到右（高位到低位）。示例：`{a[3:0], b[1:0]}` → 6 位向量（a 在前，b 在后）。 |
| `{{}}`     | `{N{expr}}`           | 将表达式 `expr` 重复 `N` 次后拼接。 | - `N` 必须为常量或编译时可确定的值。 - 示例：`{4{2'b10}}` → `8'b10101010`。 |



**注意：**

-   **高位在前，低位在后**
-   **若赋值的变量位宽不足，高位被截断；若位宽超出，高位补零。**
