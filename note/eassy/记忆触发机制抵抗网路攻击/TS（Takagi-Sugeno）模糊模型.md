### 传统Mamdani模型

Mamdani 模糊模型的**规则后件（Then部分）** 也是模糊集合，输出需要通过“解模糊化”步骤才能得到一个清晰的数值
>
>例如：”如果 `温度` 是 `高`，那么 `风扇速度` 是 `快`“。这里的“快”是一个模糊集合。

---
### TS模糊模型

TS 模糊模型的**规则后件（Then部分）** 是**输入变量的线性或常数函数**，最终的输出是所有规则输出的**加权平均**，直接得到一个清晰的数值，**省去了复杂的解模糊化过程**。
>
>例如：“如果 `温度` 是 `高`，那么 `风扇速度` = `0.8 * 温度 + 50`”。

---
### TS模糊模型结构

1. 模糊规则
>
>TS模型的规则形式：
>第 $i$ 条规则 $R_i$：
> 如果 $x_1$ 是 $A_{i_1}$ 且 $x_2$ 是 $A_{i_2}$ ... 且 $x_n$ 是 $A_{i_n}$，  
> 那么 $y_i$ = $p_{i_0}$ + $p_{i_1}$ * $x_1$ + $p_{i_2}$ * $x_2$ + ... + $p_{i_n}$ * $x_n$，
> 其中：
> $x_i$ 为输入变量；
> $A_{in}$ 为前提部分的模糊集；
> $y_i$ 是第 $i$ 条规则的输出；
> $p_in$ 是第 `i` 条规则后件的参数（常数）。

2. 推理过程
>
>对于一个给定的具体输入$X = [x_1,x_2,x_2,\cdots,x_n]$，模型的输出计算分为三步：
>1. 计算输入 `X` 对每条规则前提部分的匹配度。
>$w_i = \mu_{Ai_1(x_1)} * \mu_{Ai_2(x_2)} * ... * \mu_{Ai_n(x_n)}$
>这里 $w_i$ 表示第 $i$ 条规则的触发强度，$\mu$ 是隶属度函数。
>2. 计算每条规则的输出
>将具体的输入值 $X$ 代入该条规则的后件函数中，计算出该规则的输出值 $y_i$。
>$y_i = p_{i_0} + p_{i_1} * x_1 + p_{i_2} * x_2 + ... + p_{i_n} * x_n$
>3. 计算最终输出
>最终的模型输出 $Y$ 是所有规则输出 $y_i$ 的**加权平均**，权重就是各规则的触发强度 $ω_i$。
>$Y = (Σ (ω_i * y_i)) / (Σ ω_i)$

### TS 模糊控制器

1. 核心思路
>
>1. 首先，用T-S模糊模型来**精确表示或逼近**这个非线性系统。
>2. 然后，为这个模糊模型的**每一条规则**设计一个**对应的线性子控制器**。
>3. 最后，整个模糊控制器的输出是所有这些线性子控制器输出的**加权和**，权重与模糊模型的触发权重一致。 

2. 具体流程
>
>假设有一个T-S模糊模型来描述被控对象（包含 $r$ 条规则）。
>模型规则 $i(i = 1,2,3,\cdots,r)$：
>如果 $z_1(t)$ 是 $M_1^i$​ 且 $z_2(t)$ 是 $M_2^i$​ ... 且 $z_p(t)$ 是 $M_p^i$，  
>**那么** $\dot{x}(t) = A_ix(t)+B_iu(t)$，
>其中：
>$x(t)\in R^n$ 是状态向量，
>$u(t)\in R^m$是控制输入向量，
>$A_i​\in R^{n×n}, B_i∈R^{n×m}$ 是第 $i$ 条规则对应的线性状态矩阵和输入矩阵，
>$z_1​(t),...,z_p​(t)$是**前提变量**，它们可以是状态$x(t)$ 的函数、外部变量或时间的函数。
>
>通过模糊推理，整个系统的最终输出是所有规则输出的加权平均：
>$\dot{x}(t)=\frac{\sum _{i=1}^r w_{i}(z(t))[A_ix(t)+B_iu(t)]}{\sum_{i=1}^r w_i(z(t))} = \sum_{i=1}^r h_i(z(t))[A_ix(t)+B_iu(t)]$ 
>其中：
>$ω_i​(z(t))=∏_{k=1}^p​M^k_i​(z_k​(t))$ 是第 $i$ 条规则的**触发强度**，计算的是输入对所有前提模糊集合的匹配度，
>$h_i​(z(t))=\frac{ω_i​(z(t))}{\sum_{i=1}^r​ω_i​(z(t))}​$ 是**归一化的触发权重**，满足
>$\sum​_{i=1}^r h_i​(z(t))=1,h_i​(z(t))≥0$ 对于所有 $i$ 和 $t$ 成立
