#VSC快捷键 
## 快捷键
---
### 一、常用快捷键

#### 1.1 创建

| 文件       |  快捷键   |
| -------- | :----: |
| 当前编辑器目录下 | ctrl n |

| 终端   | 快捷键          |
| ---- | ------------ |
| 内部终端 | ctrl \`      |
| 外部终端 | ctrl shift c |

| 编辑器  | 快捷键     |
| ---- | ------- |
| 编辑器组 | ctrl 数字 |

#### 1.2 打开

| 主侧栏   |     快捷键      |
| ----- | :----------: |
| 资源管理器 | ctrl shift e |
| 文件内查找 | ctrl shift f |
| 调试器   | ctrl shift d |
| 拓展    | ctrl shift x |

| 面板    |      快捷键      |
| ----- | :-----------: |
| 终端    | ctrl shift \` |
| 调试控制台 | ctrl shift y  |
| 问题    | ctrl shift m  |
| 输出    | ctrl shift u  |
#### 1.3 切换聚焦

##### 全局切换

| 主侧栏   |     快捷键      |
| ----- | :----------: |
| 资源管理器 | ctrl shift e |
| 文件查找  | ctrl shift f |
| 调试器   | ctrl shift d |
| 拓展    | ctrl shift x |

| 面板    |      快捷键      |
| ----- | :-----------: |
| 终端    | ctrl shift \` |
| 调试控制台 | ctrl shift y  |
| 问题    | ctrl shift m  |
| 输出    | ctrl shift u  |

| 编辑器    |  快捷键   |
| ------ | :----: |
| 编辑器组 n | ctrl n |

##### 局部切换

| 编辑器   | 快捷键                                |
| ----- | ---------------------------------- |
| 编辑器组  | 上：ctrl pageup<br>下：ctrl pagedown   |
| 组内编辑器 | 上：ctrl uparrow<br>下：ctrl downarrow |

| 终端   | 快捷键                              |
| ---- | -------------------------------- |
| 终端列表 | ctrl shift \                     |
| 终端视图 | 上：ctrl pageup<br>下：ctrl pagedown |
#### 1.4 关闭

| 主侧栏 |  快捷键   |
| --- | :----: |
| 所有  | ctrl b |

| 面板    |      快捷键      |
| ----- | :-----------: |
| 终端    | ctrl shift \` |
| 调试控制台 | ctrl shift y  |
| 问题    | ctrl shift m  |
| 输出    | ctrl shift u  |

| 编辑器  |       快捷键       |
| ---- | :-------------: |
| 编辑器组 | ctrl rightarrow |
| 编辑器  |   ctrl clear    |
#### 1.5 删除

| 删除对象 |  快捷键   |
| ---- | :----: |
| 所有对象 | delete |
#### 1.6 查找

| 文件    | 快捷键    |
| ----- | ------ |
| 工作目录下 | ctrl e |

| 内容   | 快捷键          |
| ---- | ------------ |
| 当前文件 | ctrl f       |
| 所有文件 | ctrl shift f |
